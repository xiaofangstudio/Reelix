# 收尾与补齐（致 AG）

骨架铺得比预期快，M0 想验的东西基本都在了：面板齐、样式对、工程模型、图引擎、关键帧曲线、时间线命令、导出接口，Rust 侧该有的模块一个不缺。但把窗口打开、点一遍会发现，现在跑的是一个**看得清结构、但动不了的壳**——所有组件渲染的都是 `src/mock/` 里的假数据，前端没有一条真实操作能落到后端。

所以今天的任务不是把 M0 的验收项再打一遍勾，而是把断掉的线接上，让「打开就能剪」这件事成立；顺带把效果能力从纸面数字坐实，再往 84 垫一层。

## 三根断掉的线

### 界面与后端之间一根线都没连

在 `src` 下搜 `from "../services`，零命中。`App.tsx`、`TopBar`、`MediaBin`、`Monitor`、`TimelineView`、`EffectStack`、`PropertiesPanel` 全部直接读 `appStore` 里的 `mockProject` / `mockEffects` / `mockEffectKeyframes`。八个 service 文件（project、media、graph、export、history、keyframe、settings）命令名与 Rust 侧一一对应，写得没错，但**没有一个人调用它们**。

要接的对应关系是固定的：工程生命周期走 `services/project.ts`，素材箱走 `services/media.ts`，效果栈与参数走 `services/graph.ts`，关键帧走 `services/keyframe.ts`，撤销走 `services/history.ts`。store 里只留纯 UI 状态（选中项、播放头、面板开合、播放中），工程数据一律从后端回填，不在前端留副本。`services/project.ts` 里那句注释说的是这套规矩的依据——service 层是前端唯一能碰 IPC 的地方，组件不许自己 invoke。

这一根接上的判据：新建项目 → 导入一个 MP4 → 存盘 → 关掉软件 → 双击那个 `.reelix` → 素材和片段都还在。

### 监视器出不了画

`Monitor.tsx` 渲染的是「无预览」占位，播放键、逐帧键都在，但它从头到尾没调用过 `requestFrame` 或 `startPreview`。更靠下还有一层问题：`commands/render.rs` 里的 `request_frame` 第一行是 `let _ = (sequence_id, max_width, max_height);`，它不解码、不合成，只把 `frame-{time_ms}.png` 这个预期路径拼出来返回，仿佛文件已经存在，真正的解码与 wgpu 合成注释写着放到 M2。

这两件事都得动。今天要的是一条最小可用链路：解出真的一帧 → 过内部图数据到 `output` → 落进缓存目录 → 前端把它刷上去。画质可以先让（单轨、1280 宽、丢帧放过、25fps 即可），但**必须是真像素**，不能是路径字符串。判据是播放头拖到哪，画面就跟到哪，同一个时间点第二次请求走缓存不再重算。

### 时间线动不了

`TimelineView.tsx` 是只读的，`PX_PER_MS = 0.06` 写死，注释说缩放留到 M1。可后端 `commands/timeline.rs` 里的 `add_clip`、`move_clip`、`trim_clip`、`split_clip`、`delete_clips`、`set_clip_speed`、`add_track`、`remove_track` **全是能跑的真实现**——`trim_clip` 会按速度重算时长，`split_clip` 会校验切割点是否落在片段内部并按速度换算入出点，`set_clip_speed` 卡了 0.1\~100 的范围。前端一个都没调，`services/` 下甚至没有 `timeline.ts`。

补的是 `services/timeline.ts` 加画布交互：拖动改位置、两端修剪、Ctrl+K 切割、框选与多选、Delete 删除、右键菜单、6px 吸附与参考线、Ctrl+滚轮以鼠标为锚缩放。每一步落库后，由后端返回的权威数据回填，本地算完就完事的情况要避免。判据是拖一段、切一刀、删一段、改一次速度，撤销 20 步能全退回去。

## 效果能力：先把 74 坐实，再够到 84

有个前提要说清楚：**74 不是现状，是目标态**。骨架里 27 个效果目前全是参数卡片，`graph/engine.rs` 能算 fingerprint、能做脏标记传播和缓存复用，但输出的不是像素。换句话说这一项现在的真实值不在 74 附近，比它低得多。今天要做的是两件事一起干——把效果这条线接通让它值 74，再把 84 缺的那口气垫上。

| 构成 | 权重 | 骨架现值 | 今天要到的位置 | 84 需要的位置 |
| --- | --- | --- | --- | --- |
| 效果覆盖与出图 | 20 | 27 个只有名字，出图 0 | 变换 / 颜色 / 滤镜 / 合成四类走通 | 27 个里 20 个以上能出图 |
| 参数实时生效 | 25 | 0 | 拖动即变，无「应用」按钮 | 参数响应 ≤100ms |
| 关键帧与曲线 | 20 | 曲线编辑器真算法，但空转 | 拖关键帧，画面跟着变 | 全参数可打关键帧 |
| 抠像 / 蒙版 / 粒子 | 20 | 0 | 至少各有一个可用版本 | 边缘过渡自然、可叠加 |
| 融合与预设 | 15 | 0 | 混合模式先上 5\~6 种 | 预设可存可取可复用 |
| 合计 | 100 | 约 40 | 约 74 | 约 84 |

这里最划算的一处是曲线编辑器。`CurveEditorView.tsx` 已经是个真东西——原生 SVG、160 点密采样、拖钻石、框选、播放头拖动、拖动时冻结值域防止抖动，而且采样用的是与 Rust `keyframe/curve.rs` 同一套贝塞尔算法，画出来的就是引擎的计算结果。它今天唯一的问题是拖完不影响任何画面，因为 `evaluate_param` 没有接进渲染。把这张图与被改的参数绑起来，2 分的增量几乎是白拿的。

色度抠图、蒙版、粒子这三样是你点过名的「一个都不准少」，规格里色度抠图排在 M2。今天不要求做全，但至少各出一个能看见结果的版本：色度抠图要吸管取色 + 容差 + 边缘羽化 + 溢色抑制；蒙版要矩形、椭圆、自由路径加羽化和反转；粒子要有一组能跑起来的发射器参数。

## 还缺哪些主流能力

下面这些是剪映、Pr、达芬奇、Blurrr 都有的东西，对着抄不丢人，缺了才丢人。按对「能不能剪」的影响排：

| 能力 | 主流软件 | Reelix 现状 | 影响 |
| --- | --- | --- | --- |
| 源 / 节目双监视器 | 全都有 | 只有单监视器，且不出画 | 没法对照素材与成片 |
| 入出点 I/O | 全都有 | 无 | 取不出一段，只能用整条素材 |
| J / K / L 变速播放 | Pr、达芬奇 | 无 | 审片效率差一档 |
| 循环播放 | 全都有 | 无 | 反复看同一段要手点 |
| 示波器 / 安全框 / 网格 | Pr、达芬奇 | 无 | 调色是瞎调 |
| 转场 | 全都有 | 无 | 两个片段只能硬切 |
| 音频增益与淡入淡出 | 全都有 | 无 | 声音会突然炸一下 |
| 预设面板（存当前效果栈） | AE、Pr、达芬奇 | 无 | 每段都要重搭一遍 |
| 复合片段（预合成） | 全都有 | 后端有 `collapse_compound` / `enter_compound`，前端没入口 | 复杂镜头没法收敛 |
| 素材文件夹（上传素材 / 音效 / 音乐 / 图像 / 工程） | 你点名的 | 无 | 进软件看不到自己的库 |
| 快捷键系统 | 全都有 | 无 | 现在只有空格和方向键能猜 |
| 色彩空间管理 | Pr、达芬奇 | Rec.709 只写在 mock 里 | 导入素材颜色会跑 |
| 自动保存 | 全都有 | 无 | 崩一次全没 |

今天不必全上，但「主流清单」里排前四的那几样（双监视器、I/O、JKL、循环）加起来工作量不大，是性价比最高的一档。

## 致命缺陷：这几处不补，压根不能剪

按严重程度排，前四条是今天必须清的。

**界面与后端零连接。** 全站没有一处 service 引用，这是「看起来像软件」和「是软件」之间的分界线。状态再漂亮，用户按下去没反应，第一分钟就会关掉。

**没有画面。** 监视器是占位，就算把它接上 `requestFrame`，`request_frame` 也不解码。一个给不出画面的剪辑软件等于不存在。

**时间线不能改。** 只读、命令全没接。素材放上去就动不了，这是「无法剪辑」这四个字最直接的来源。

**录音整块缺席。** 它排在 M1，也是你点名的六样之一。现在音频是真空的——没有波形、没有增益、没有淡入淡出，录音入口也没有。这一块不动，音频轨上那片空白会一直空着。

后面这几条不卡「今天能不能剪」，但卡「剪出来是不是能看的片子」：

**素材导入是半假的。** `import_media` 本身没问题，会去重、会往工程里追加 Asset，但 `probe_path` 返回的是全零——`duration_ms: 0.0`、`width: 0`、`height: 0`、`frame_rate: 0.0`，类型只靠文件扩展名猜。这意味着即便时间线接好了，片段时长算出来还是 0，放到轨道上就是一格。缩略图同理，`generate_thumbnail` 只返回一个预期路径。这两处必须接真解码探测。

**导出是个死按钮。** `TopBar` 的「导出」没有 onClick，菜单七个按钮也不展开。后端 `export.rs` 和 `services/export.ts` 都齐，就是没人调。导出按规矩排在 M4，今天可以不做，但不能继续让它假装有功能。

**撤销没有入口。** `history` 模块和 `services/history.ts` 都在，UI 里没有触发点。

**动画与渲染之间少了一份契约。** 关键帧存的是曲线，渲染要的是某一帧的取值，中间靠 `evaluate_param` 连着。这条不接，前面所有「打关键帧」的动作都落不到画面上。

顺手对齐一处口径：`docs/02-功能规格.md` 的颜色类表里列了「色键」，抠像类表里又列了「色度抠图（色键）」；代码里数是颜色 4 个、抠像 1 个。两套数对不上，后面按文档对账的人会绕。今天把文档改到与代码一致。

## 要剪得更好，还得加什么

真正决定「剪得爽不爽」的不是效果数量，是**参数一动、画面就动**。这条做到位，用户会觉得这是个能用的工具；做不到位，堆到 50 个效果也只是幻灯片。所以实时反馈优先级高于新效果。

手感上按 `docs/11` 那一套走：拖动跟手、不设「应用」按钮；时间线缩放以鼠标为锚；吸附带宽 6px 并画参考线；空格播放暂停、J/K/L 变速、I/O 打入出点、方向键逐帧、Shift 十倍；效果搜索支持中文与拼音首字母；出错给中文人话，不给错误码。

成片感来自三处：转场、音频淡化、复合片段。转场哪怕先做三个（叠化、黑场、白闪）也够用；音频淡化是消除「炸音」的最低成本手段；复合片段是把复杂镜头收敛成一段的唯一办法，后端已经能折叠了，缺的只是一个入口。

调色这一侧，示波器、安全框、网格是分水岭。没有示波器，用户是在凭感觉拉滑块，做出来的片子在不同屏幕上一片惨白，这种成片很难算「效果达到 84」——分数的构成里，能被一眼看出不对的地方，扣得比想象中重。

## 收工前

`AGENTS.md` 里那份交付前自检照旧走一遍，另外这三条是硬门槛：`npx tsc --noEmit` 零错误，`cargo clippy` 零 warning，`cargo test` 全过。骨架期留下的 `unwrap()`、`console.log`、硬编码颜色，接线的过程中顺手清掉，别留给 M2 的人。

红线再念一遍，今天也别碰：配色只用白底加 `#26734f` 与 `#57c08f`，**不许出现紫色**；Reelix 是特效合成软件，界面里没有节点图、没有连线；全中文界面；无 AI、无账号、无自动更新；不执行任何 git 提交或推送；M6 已删除，也没有任何流体或液态相关的东西。
