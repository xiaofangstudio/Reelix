# 03 · 技术架构

---

## 一、技术栈

| 层 | 选型 | 版本 | 说明 |
| --- | --- | --- | --- |
| 应用外壳 | Tauri | v2 | 不是 Electron。体积与内存都更可控 |
| 后端语言 | Rust | 1.75+ | 解码、合成、导出、文件、IPC |
| GPU | wgpu | 0.20+ | 统一走 WebGPU 抽象，Windows 上落到 DX12/Vulkan |
| 解码 | FFmpeg | 6.0+ | **动态链接**（LGPL-2.1 要求） |
| 前端框架 | React | 18 | 严格模式 |
| 前端语言 | TypeScript | 5.6+ | `strict` + `noUnusedLocals` |
| 构建 | Vite | 5 | dev 端口 **1422** |
| 状态管理 | Zustand | 4.5+ | 不要 Redux |
| 样式 | 原生 CSS 变量 | — | 见 [05](05-界面规范.md) |
| 时序数据 | 自研关键帧引擎 | — | 见 [04](04-剪辑与特效融合设计.md) 第三节 |

### 不引入的东西

Tailwind、shadcn、Radix、MUI、Ant Design、Chakra、styled-components、Redux、MobX、Moment.js、Lodash（用原生或手写小工具）。

理由：安装包体积红线、样式可控性、以及「不要一堆依赖」。**每引入一个依赖都要先过许可证白名单。**

## 二、分层

```
┌──────────────────────────────────────────────────────────────┐
│  表现层  React + TS                                          │
│  ┌──────────┬──────────┬──────────┬──────────┬────────────┐ │
│  │ 素材箱    │ 监视器    │ 时间线    │ 效果栈    │ 属性面板    │ │
│  └──────────┴──────────┴──────────┴──────────┴────────────┘ │
│  只做界面与交互。不做解码、不做合成、不做逐帧处理。              │
└──────────────────────────┬───────────────────────────────────┘
                           │ Tauri IPC（invoke + event）
┌──────────────────────────┴───────────────────────────────────┐
│  核心层  Rust                                                │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  图引擎  节点注册表 · 脏标记 · 拓扑排序 · 并行求值调度     │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  时间线模型  片段 · 轨道 · 序列 · 时间映射                │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  关键帧引擎  曲线求值 · 贝塞尔 · 缓动预设                 │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  合成器  wgpu 管线 · 多轨混合 · 转场 · 色彩管线           │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  解码器池  硬件解码 · LRU 帧缓存 · 帧精确寻址             │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  导出管线  编码 · 封装 · 进度回报                         │ │
│  ├────────────────────────────────────────────────────────┤ │
│  │  撤销栈  命令模式 · 与前端共享历史                        │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────┬───────────────────────────────────┘
                           │
┌──────────────────────────┴───────────────────────────────────┐
│  系统层  文件系统 · 系统解码器 · 音频设备 · 显示与窗口          │
└──────────────────────────────────────────────────────────────┘
```

**核心原则：所有重活都在 Rust 侧。** 前端拿到的永远是「已经算好的帧」或「已经算好的数值」，不是「要自己算的原始数据」。

## 四、Tauri 命令契约

命令名一律 snake_case，动词开头。参数与返回值全部 camelCase（serde rename_all）。

### 项目

| 命令 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `new_project` | `{name: string}` | `Project` | 新建项目 |
| `open_project` | `{path: string}` | `Project` | 打开 .reelix |
| `save_project` | `{path?: string}` | `{path: string}` | 保存，无路径时弹保存框 |
| `get_project` | — | `Project` | 取当前项目快照 |
| `close_project` | — | `bool` | 关闭并清理 |

### 素材

| 命令 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `import_media` | `{paths: string[]}` | `Asset[]` | 导入素材，返回元数据 |
| `probe_media` | `{path: string}` | `MediaInfo` | 只探测不导入 |
| `relink_media` | `{assetId: string, newPath: string}` | `bool` | 重新链接 |
| `remove_media` | `{assetId: string, deleteFile: bool}` | `bool` | 移除引用；`deleteFile` 为真时删磁盘文件 |
| `generate_thumbnail` | `{assetId: string, timeMs: number}` | `{path: string}` | 生成缩略图 |

### 时间线

| 命令 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `add_clip` | `{sequenceId, trackId, assetId, startMs, durationMs}` | `Clip` | 加片段 |
| `move_clip` | `{clipId, trackId, startMs}` | `bool` | 移动 |
| `trim_clip` | `{clipId, inMs, outMs}` | `bool` | 修剪 |
| `split_clip` | `{clipId, atMs}` | `Clip[]` | 切割 |

| 命令 | 参数 | 返回 | 说明 |

| 命令 | 参数 | 返回 | 说明 |

## 五、数据模型（前端类型，字段名即契约）

```ts
type Id = string;

interface Project {
  id: Id;
  name: string;
  createdAt: number;
  modifiedAt: number;
  assets: Asset[];
  sequences: Sequence[];
  graphs: Record<Id, Graph>;      // 每个序列有自己的根图
  settings: ProjectSettings;
}

interface Asset {
  id: Id;
  path: string;
  name: string;
  kind: "video" | "audio" | "image" | "imageSequence";
  durationMs: number;
  width: number;
  height: number;
  frameRate: number;
  codec: string;
  hasAudio: boolean;
  missing: boolean;               // 文件找不到了
}

interface Sequence {
  id: Id;
  name: string;
  width: number;
  height: number;
  frameRate: number;
  colorSpace: string;
  durationMs: number;
  tracks: Track[];
  rootGraphId: Id;                // 该序列的根图（仅内部求值，界面不暴露）
}

interface Track {
  id: Id;
  kind: "video" | "audio";
  index: number;
  muted: boolean;
  solo: boolean;
  locked: boolean;
  hidden: boolean;
  height: number;
  clips: Clip[];
}

interface Clip {
  id: Id;
  assetId: Id;
  trackId: Id;
  startMs: number;                // 在序列上的起点
  durationMs: number;
  inMs: number;                   // 素材内的入点
  outMs: number;                  // 素材内的出点
  speed: number;
  reversed: boolean;
  nodeId: Id;                     // 对应的图节点
  compoundId?: Id;                // 若是复合片段
}
```

```ts
interface Graph {
  id: Id;
  nodes: GraphNode[];
  connections: Connection[];
  parentNodeId?: Id;              // 属于哪个复合片段
}

interface GraphNode {
  id: Id;
  type: string;                   // 注册表里的类型键
  name: string;                   // 中文显示名，用户可改
  x: number;
  y: number;
  params: Record<string, ParamValue>;
  bypassed: boolean;
  collapsed: boolean;             // 折叠为复合片段
  inputs: Plug[];
  outputs: Plug[];
}

interface Plug {
  key: string;
  label: string;                  // 中文
  dataType: "image" | "number" | "vector" | "color" | "text" | "mask";
  connected: boolean;
}

interface Connection {
  id: Id;
  fromNode: Id;
  fromPlug: string;
  toNode: Id;
  toPlug: string;
}
```

```ts
interface Keyframe {
  id: Id;
  targetId: Id;                   // 片段 id 或节点 id
  param: string;
  timeMs: number;
  value: number;
  easing: "linear" | "ease-in" | "ease-out" | "ease-in-out" | "bounce" | "elastic";
  inTangent: { x: number; y: number };
  outTangent: { x: number; y: number };
}

interface Curve {
  targetId: Id;
  param: string;
  keyframes: Keyframe[];          // 按 timeMs 升序
}
```

## 六、项目文件格式

`.reelix` 是一个 **ZIP 容器**（后缀改成 .reelix），内部：

```
project.json          项目结构（上面的数据模型序列化）
thumbnail.png         项目缩略图（时间线第一帧）
meta.json             版本号、创建时间、Reelix 版本
```

**不内嵌素材**，只存路径引用。理由：素材动辄几十 GB，内嵌不现实。素材丢失时用「重新链接」解决。

**向后兼容：** `meta.json` 里写 `formatVersion`。打开旧版本文件时走升级路径；打开比当前新的版本时明确报错，不要尝试解析。

## 七、本地存储路径

| 用途 | 路径 |
| --- | --- |
| 配置 | `%APPDATA%\Reelix\settings.json` |
| 自动保存 | `%APPDATA%\Reelix\autosave\` |
| 缩略图与胶片带缓存 | `%LOCALAPPDATA%\Reelix\cache\thumbnails\` |
| 波形缓存 | `%LOCALAPPDATA%\Reelix\cache\waveforms\` |
| 预览帧缓存 | `%LOCALAPPDATA%\Reelix\cache\preview\` |
| 日志 | `%LOCALAPPDATA%\Reelix\logs\` |

缓存目录可在设置里改。**缓存必须有上限，超了自动清理最旧的。** 默认上限 20GB。

## 八、性能契约

| 指标 | 目标 | 不可接受 |
| --- | --- | --- |
| 冷启动到可用 | ≤ 3 秒 | > 6 秒 |
| 1080p 预览帧率 | 稳定 60fps | 掉到 30fps 以下且无降级 |
| 拖动参数滑块到画面更新 | ≤ 100ms | > 300ms |
| 时间线拖动片段 | 跟手，无卡顿 | 明显延迟 |
| 解码单帧 | ≤ 10ms | > 33ms |
| 导出速度 | 不低于源时长的 1/4 | 慢于实时 |
| 空闲内存占用 | ≤ 400MB | > 1GB |

达不到时的降级顺序：**降预览分辨率 → 降预览帧率 → 降画质**。降级必须让用户看得见（监视器角落提示），不能偷偷降。

## 九、安全与权限

- Tauri capabilities 只开需要的：文件读写（限用户选择的路径）、对话框、系统信息
- **不开** shell 执行、不开任意 HTTP 请求
- **没有网络行为**（除用户主动导入导出时访问本地文件）
- CSP：`default-src 'self'; img-src 'self' asset: data: blob:; style-src 'self' 'unsafe-inline'; script-src 'self'`
- 项目文件解析要对畸形输入健壮（zip 炸弹、超深嵌套、超大数组）
