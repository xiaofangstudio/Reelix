# 05 · 界面规范

本文档是 Reelix 视觉与交互的唯一权威来源。所有颜色值、间距、组件尺寸以本文档为准，代码里的 `src/styles/tokens.css` 必须与本文档一致。

---

## 一、最高优先级：品牌双色制

> **⚠️ 配色修订：本文下方「深色为默认 + 品牌蓝作强调色」的方案已作废。**
>
> Reelix 现定为 **白 + 浅绿**，与深色系的 Strata 刻意拉开差距。唯一权威是 [`scaffold/src/styles/tokens.css`](../scaffold/src/styles/tokens.css)：
> - 默认主题是**浅色**（`:root`，白底），深色降为备选
> - 界面强调色 `--rl-accent: #26734f`（对白底 5.2:1，达 AA）；填充按钮 `--rl-accent-fill: #57c08f`
> - 小方品牌蓝 `#6fc0ff` 只保留在 logo 与「关于」页，**不再作界面强调色**
> - 3D 摄像机、内置字体、预设动效见 [09-3D摄像机与素材库.md](09-3D摄像机与素材库.md)
>
> 下文的排版、间距、组件结构、交互规范仍然有效，**仅颜色取值**以上述令牌为准。

**全应用只有两味色：中性白 + 浅绿。（原为中性黑 + 品牌蓝，已修订）**

- **中性白**：从纯白到浅灰的一整套中性色阶，负责背景、面板、边框、正文
- **浅绿**：`#26734f`，**唯一强调色**。负责选中态、激活态、关键元素、焦点环；填充按钮用 `--rl-accent-fill: #57c08f`

**严禁紫色。严禁任何第二强调色。** 除浅绿以外的彩色（橙色、粉色、紫色、其它绿调的荧光绿）一律不准用作界面强调色（状态色除外，见第五节）。用户为紫色发过一次火，不要再犯。

品牌蓝 `#6fc0ff` 的来源：小方工作室 logo 外圈取样值。**它现在只保留在 logo 与「关于」页，不再作界面强调色。**

### 对比度规则（重要）

`#6fc0ff` 在浅色底上的对比度只有约 1.97:1，**不过 WCAG AA**，因此不再承担界面强调职责。界面强调色统一用浅绿：

| 场景 | 用什么绿 | 前景色 |
| --- | --- | --- |
| 浅色主题（默认） | `#26734f` 直接作强调（对白底 5.2:1，过 AA） | 配白字 |
| 深色主题（备选） | 提亮一档 `#57c08f` | 配深墨字 `#06121f` |
| 大面积填充（两种主题） | `--rl-accent-fill: #57c08f` | 用正文色 |

**永远不要把 `#6fc0ff` 当界面强调色或浅底上的文字色。**

## 二、配色令牌

> **⚠️ 本节标题与下方「深色主题（默认）」的命名已被上方配色修订块作废。** 默认主题是**浅色**（白 + 浅绿）；「深色主题」一节现在指的是**备选**主题，令牌名称保留是为了兼容 `tokens.css`。下面这句旧话不再成立：

~~Reelix 是专业工具软件，**默认深色主题**（剪辑时深色不干扰对画面的判断）。浅色主题作为可选。~~

## 三、字体与排版

**界面层不打包任何字体文件**（安装包体积的敌人），界面文字全部用系统字体栈。**内容层**（文字层、字幕、三维文字）另有一套**内置字体库**，随包分发，见 [09-3D摄像机与素材库.md](09-3D摄像机与素材库.md) 第三节。本节所列字体栈只作用于界面。

```css
--rl-font-ui: "PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei",
              system-ui, -apple-system, "Segoe UI", sans-serif;
--rl-font-mono: "Cascadia Mono", "Consolas", "SF Mono", ui-monospace, monospace;
```

| 用途 | 字号 | 字重 | 行高 | 字体 |
| --- | --- | --- | --- | --- |
| 窗口标题 | 13px | 500 | 1.4 | UI |
| 菜单栏 | 13px | 400 | 1.4 | UI |
| 面板标题 | 12px | 600 | 1.4 | UI |
| 正文 / 参数名 | 12px | 400 | 1.5 | UI |
| 参数值（数值） | 12px | 400 | 1.4 | **Mono**，右对齐 |
| 时间码 | 13px | 500 | 1.4 | **Mono** |
| 轨道名 | 11px | 500 | 1.4 | UI |
| 片段名 | 11px | 400 | 1.3 | UI |
| 提示 / 次要信息 | 11px | 400 | 1.4 | UI |
| 效果名 / 图层名 | 12px | 500 | 1.3 | UI |
| 对话框标题 | 15px | 600 | 1.4 | UI |
| 空状态主文案 | 14px | 500 | 1.5 | UI |
| 空状态副文案 | 12px | 400 | 1.5 | UI |

**专业工具的字号比网页小。** 不要用 16px 正文，那是网页的尺寸。界面密度是专业软件的一部分。

**数字一律用等宽字体**，且右对齐。时间码、参数值、帧号、文件大小，全部等宽。这样数值跳动时不会左右晃。

## 四、间距、圆角、描边

```css
--rl-space-1: 2px;
--rl-space-2: 4px;
--rl-space-3: 6px;
--rl-space-4: 8px;
--rl-space-5: 12px;
--rl-space-6: 16px;
--rl-space-7: 24px;

--rl-radius-sm: 3px;    /* 输入框、小按钮 */
--rl-radius-md: 5px;    /* 面板、卡片 */
--rl-radius-lg: 8px;    /* 对话框 */
--rl-radius-pill: 999px;

--rl-border-w: 1px;
--rl-focus-w: 2px;
```

**圆角要小。** 3 到 8px。专业工具不是网页，不要 16px 以上的圆角。

## 五、状态色

状态色**只准表达状态**，不准当强调色用。

| 用途 | 深色 | 浅色 | 出现位置 |
| --- | --- | --- | --- |
| 成功 / 已完成 | `#3fa96a` | `#1a8f4c` | 导出完成、缓存清理完成 |
| 警告 / 需注意 | `#c9973f` | `#b7791f` | 素材丢失、预览降级、缓存将满 |
| 错误 / 失败 | `#d4574e` | `#d92d20` | 解码失败、导出失败、磁盘不足 |

状态色**不要用来做按钮、不要用来做选中态**。选中态永远是浅绿 `--rl-accent`。

## 六、组件规范

### 6.1 顶栏（48px）

```
┌──────────────────────────────────────────────────────────────────┐
│ 文件  编辑  序列  素材  特效  视图  帮助                    [导出] │
└──────────────────────────────────────────────────────────────────┘
```

- 高度 48px，背景 `--rl-surface`，底部 1px `--rl-border`
- 菜单项：高 28px，左右内边距 10px，圆角 3px，悬停 `--rl-surface-3`
- 「导出」按钮：浅绿填充 `--rl-accent-fill`，文字 `--rl-accent-ink`，高 28px，左右内边距 14px，圆角 3px
- 菜单展开用系统风格的下拉，不要自绘花哨动画

### 6.2 面板（Panel）

- 面板标题栏：高 28px，背景 `--rl-surface-2`，标题 12px/600，左侧内边距 8px
- 标题栏右侧放该面板的操作按钮（折叠、菜单），图标 14px
- 面板可折叠：折叠后只留 32px 竖条，竖条上竖排显示面板名
- 分隔条：4px 宽，悬停时变浅绿半透明

### 6.3 时间线片段（Clip）

```
┌──────────────────────────────┐
│ 采访.mp4                     │   ← 11px，左内边距 6px
│ ▁▂▃▅▇▅▃▂▁                    │   ← 音频波形（音频片段）或缩略图（视频片段）
└──────────────────────────────┘
```

- 高度随轨道高度
- 背景 `--rl-clip-video` / `--rl-clip-audio`
- 圆角 3px
- 左右边缘各 8px 是修剪热区，鼠标移上去变成修剪光标
- **选中态**：2px 浅绿描边 + 轻微提亮
- 片段名过长时截断加省略号
- 视频片段默认显示胶片带（首尾帧 + 中间帧缩略图）；关掉时只显示纯色 + 名称

### 6.4 效果栈卡片（EffectCard）

选中一个片段后，右侧属性面板下部就是它的**效果栈**。每个效果是一张纵向排列的折叠卡片：

```
┌──────────────────────────────┐
│ ⏻  模糊                 ⋮⋮ ⌄ │   ← 标题栏：开关 / 效果名 / 拖拽把手 / 折叠
├──────────────────────────────┤
│ 半径         [   12 ] ⏱  ⌇  │   ← 参数行（左侧秒表打关键帧）
│ 类型         [  高斯  ▾ ]    │
└──────────────────────────────┘
```

- 卡片占满属性面板宽度（300px 面板，减去两侧 12px 内边距）
- 标题栏高 26px：最左是**旁路开关**（⏻），中间效果名 12px/500，右侧是拖拽把手与折叠箭头
- **开关未旁路**：实心浅绿；**已旁路**：空心灰 + 整卡 50% 透明 + 效果名加删除线
- **折叠**：收起后只留标题栏，折叠状态记忆在项目里
- 主体背景 `--rl-stack-card-bg`，标题栏 `--rl-stack-card-header`，1px `--rl-stack-card-border`
- 圆角 5px，卡片间距 4px
- **选中态**：卡片左缘 2px 浅绿竖条（`--rl-stack-card-selected`），不整框描边，堆叠时不花
- 打了关键帧的参数行：行左显示一个 6px 浅绿圆点

**添加 / 排序 / 删除（关键交互）：**

- **添加**：从「效果库」把效果拖到片段上，或拖到效果栈两卡之间的插入位即添加
- **排序**：按住拖拽把手（⋮⋮）上下拖动改顺序，插入位显示一条 2px 浅绿横线
- **删除**：卡片标题栏右键 → 删除，或选中后按 Delete
- 整条栈自上而下按顺序处理，**最上面一张最靠近源素材（先执行）**，最下面一张靠近输出
- 效果名下面的参数行直接内联展开，不需要弹窗

### 6.5 图层行（LayerRow）

属性面板顶部是**图层树**（当前序列 / 复合片段的图层列表），每行对应一个图层（片段）：

```
│ ▸ 👁 🔒  采访.mp4            │
│    👁 🔒  标题文字            │
│ ▸ 👁 🔒  背景.png            │
```

- 行高 26px，缩进按层级，缩进引导线用 `--rl-layer-indent`
- 最左是**展开箭头**（有子层或有效果栈才显示），随后是显隐（眼睛）、锁定图标，图标 14px
- 图层名 12px/500，过长截断加省略号
- 行底 `--rl-layer-row-bg`
- **选中态**：整行铺 `--rl-accent-soft` 底色 + 左侧 2px 浅绿竖条（`--rl-layer-row-selected`）
- 拖动图层行可改变图层顺序（对应时间线的叠放顺序），跨层拖可建立父子关系
- 双击图层名可重命名
- 图层行与时间线轨道**共用同一份选中态**：在图层树里选中的图层，时间线上对应片段同步高亮，反之亦然

### 6.6 参数行（ParamRow）

```
不透明度        [  100  ] %   ⏱  ⌇
```

- 左侧参数名 12px，宽 90px
- 中间数值输入框：宽 72px，高 22px，背景 `--rl-surface-3`，圆角 3px，等宽字体右对齐
- 右侧秒表按钮（⏱）与曲线按钮（⌇），各 18px
- 秒表未激活：描边空心；已激活：浅绿实心
- 参数被关键帧控制时，输入框背景变成 `--rl-accent-soft`

**数值输入框的交互（很重要）：**

- 点击进入编辑，全选
- **鼠标在数值上左右拖动可连续调值**（专业软件的标准交互），拖动时步进按参数类型定
- 上下方向键微调，按住 Shift 步进 ×10
- 回车确认，Esc 取消
- 非法输入时框边变红并抖动，不静默接受

### 6.7 曲线编辑器

- 背景 `--rl-surface`，网格用 `--rl-grid` 的 1px 线
- 曲线 2px 浅绿
- 关键帧：8px 菱形，填充浅绿，选中时加白描边
- 贝塞尔手柄：4px 圆点 + 1px 连线
- 时间轴在底部，值轴在左侧，刻度用等宽字体
- 多参数同屏时，**每条曲线用不同线型区分**（实线/虚线/点线），不要用不同颜色——因为只有两味色

### 6.8 对话框

- 宽度：简单确认 380px，表单类 520px
- 圆角 8px，背景 `--rl-surface`，`--rl-shadow-lg`
- 标题 15px/600，正文 12px，行高 1.6
- 按钮在右下角，主按钮在右
- 主按钮：浅绿填充 `--rl-accent-fill`。次按钮：描边式
- 遮罩：`rgba(0,0,0,0.5)`

### 6.9 空状态

居中，垂直堆叠：图标（32px，`--rl-text-faint`）→ 主文案（14px/500）→ 副文案（12px，`--rl-text-dim`）→ 按钮。

### 6.10 进度与状态提示

- 顶栏右侧或底栏显示进行中的任务
- 进度条高 4px，填充浅绿 `--rl-accent-fill`，底 `--rl-surface-3`
- 必须显示：任务名、进度百分比、预计剩余时间
- 可取消的任务必须有取消按钮

## 七、动效

**专业工具要快，不要炫。**

| 场合 | 时长 | 缓动 |
| --- | --- | --- |
| 悬停变色 | 100ms | ease-out |
| 面板折叠展开 | 160ms | ease-out |
| 对话框出现 | 140ms | ease-out（透明度 + 4px 上移） |
| 选中态变化 | 80ms | linear |
| 效果添加 / 图层插入 | 120ms | ease-out（缩放 0.96 → 1） |

**禁止：** 弹跳动画、旋转加载图标（用进度条代替）、超过 250ms 的过渡、视差效果、粒子装饰。

**关键：任何动效都不能阻塞交互。** 动画播放期间用户的操作必须立刻生效。

## 八、图标

- 统一线性风格，描边 1.5px，尺寸 14 / 16 / 20px 三档
- 颜色跟随 `currentColor`
- 首版用自绘 SVG，不引图标库（体积 + 许可证双重考虑）
- **图标必须配文字标签**，或至少有 tooltip。纯图标按钮在专业软件里是可用性陷阱

## 九、与同类软件的区隔

### 9.1 整体气质：友好亲切，不做作

用户明确定调：**界面要「看起来很友好」**——第一眼愿意上手、不劝退、不寒酸，但**不是幼稚的「可爱」**，也不堆花哨装饰。

- **友好**：留白舒服、字重清爽、圆角克制（3~8px）、图标是实心简笔而非线框细描；空状态给一句人话引导，不留白板。
- **亲切**：文案是「导入素材」这种动宾短句，不端着；参数有中文名，不拿英文缩写吓人。
- **上手即用**：常用功能在**一级界面**就能摸到，进阶参数收进「高级」折叠区，不分「简单模式 / 专业模式」两套。
- **极致扁平**：不堆阴影、不堆渐变、不堆描边套描边。层次靠间距与浅灰分隔，不靠立体感。

> 反面清单：不做拟物、不做霓虹发光边框、不做卡通吉祥物、不做满屏动画。**「友好」来自清晰与松弛，不来自装饰。**
