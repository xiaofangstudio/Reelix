# 02 · 功能规格

本文档定义 Reelix 的窗口布局、功能模块、交互细节与边界。所有界面文案以本文档为准。

> **定位提醒：** Reelix 是**特效合成软件**（合成优先，剪辑是附属能力）。界面上**没有节点图，也没有连线**——特效以「**效果栈**」表达：选中一个片段，右侧属性面板就出现它的效果栈，效果是纵向排列的折叠卡片。剪辑与合成是**同一份数据的两种看法**：下半区「时间线」看时间顺序，属性面板的「效果栈」看处理链顺序，两者实时双向联动。菜单里「特效」类目下应优先出现**合成与空间识别**相关项，不要把它们埋在二级菜单。核心设计详见 [04-剪辑与特效融合设计.md](04-剪辑与特效融合设计.md)，空间识别详见 [10-特效合成与空间识别.md](10-特效合成与空间识别.md)。

---

## 一、窗口

| 项 | 值 |
| --- | --- |
| 默认尺寸 | 1600 × 950 |
| 最小尺寸 | 1180 × 720 |
| 启动位置 | 屏幕居中 |
| 标题栏 | 系统原生标题栏，标题格式 `文件名 — Reelix`，未保存时前缀 `• ` |
| 关闭行为 | 有未保存改动时弹确认框；关闭后**进程必须完全退出**，不允许后台残留 |
| 全屏 | 支持 F11 全屏 |

## 二、主界面布局

Reelix 采用**四区布局**。所有面板都可折叠、可拖动分隔条、可单独最大化。

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏 48px  文件  编辑  序列  素材  特效  视图  帮助        [导出] │
├──────────┬───────────────────────────────────────┬───────────────┤
│          │                                       │               │
│  素材箱   │            监视器                      │   属性面板     │
│  240px   │        （节目监视器 / 源监视器）        │    300px      │
│          │                                       │               │
│  素材列表 │                                       │  ┌──────────┐ │
│  搜索框   │                                       │  │ 参数区    │ │
│  导入按钮 │                                       │  │ 效果栈    │ │
│          │                                       │  │ 关键帧    │ │
│          │                                       │  └──────────┘ │
├──────────┴───────────────────────────────────────┴───────────────┤
│ 时间线 / 曲线编辑器  （标签页切换，默认时间线）      高度 320px 起  │
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │ 工具栏：选择 剃刀 吸附 缩放           [时间线 | 曲线编辑器]    │ │
│ ├──────────────────────────────────────────────────────────────┤ │
│ │ V2  ▓▓▓▓▓▓▓▓        ▓▓▓▓▓▓▓▓▓▓▓▓▓▓                          │ │
│ │ V1  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                  │ │
│ │ A1  ～～～～～～～～～～～～～～～～～～～～～～～～～              │ │
│ └──────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

**布局规则：**

- 素材箱与属性面板可以各自折叠（折叠后留 32px 竖条）
- 下半区（时间线 / 曲线编辑器）高度可拖拽，范围 200px 到窗口高度的 70%
- 所有分隔条位置记入项目文件，下次打开恢复
- **下半区是「时间线」与「曲线编辑器」两个标签页**。特效**不占独立区域**——它以挂在片段上的**效果栈**形式出现在属性面板里。**时间线轨道与效果栈是同一份数据的两种看法**，这是融合设计的界面体现

## 三、模块 A：素材箱

### A1 素材列表

每条素材显示：缩略图、文件名、时长、分辨率、帧率、编码格式。

- 支持列表视图与网格视图切换
- 支持按名称、时长、导入时间、类型排序
- 顶部搜索框实时过滤（支持中文与拼音首字母）
- 左侧显示「**上传素材**」文件夹树，可展开折叠

### A1.1 「上传素材」文件夹结构（用户点名要的）

软件首次启动时，在用户数据目录下自动创建这棵**固定、清晰易懂**的目录树（详见 [10](10-特效合成与空间识别.md) 第六节）：

```
上传素材/
├── 音效/      短音效（打击、转场、环境声）
├── 音乐/      背景音乐、BGM
├── 图像/      图片、贴图、Logo
├── 视频/      实拍素材、素材库视频
├── 字体/      用户自带字体
├── 预设/      用户保存的预设特效 / 动画 / 调色
└── 工程/      工程模板、可复用的复合片段工程
```

- 这棵树**用户可见、可改**，就是普通磁盘文件夹，不是私有黑盒
- 用户在资源管理器里往里丢文件，**素材箱自动刷新**并显示
- 软件按文件**实际所在目录**归类，不强制
- 设置里可**更改根目录位置**（如放到 D 盘），软件记住路径

### A1.2 预设面板

**预设 = 可复用的「效果 + 参数 + 关键帧」打包。** 分三类：效果预设、动画预设、调色预设，全部存在 `上传素材/预设/`。

- 用户在任意图层调好效果后，点「保存为预设」→ 存进 `预设/`，**立刻出现在预设面板**
- 可搜索、可拖拽套用到任意图层/片段、可右键重命名/删除
- 预设面板与素材箱**共享同一套文件夹浏览逻辑**：进软件就能看到「上传素材」及其子目录
- 预设支持文件夹分组（用户可在 `预设/` 下再建子目录）

### A2 导入

| 方式 | 行为 |
| --- | --- |
| 点「导入」按钮 | 打开系统文件选择框，支持多选 |
| 拖文件到素材箱 | 直接导入 |
| 拖文件到时间线 | 导入并直接放到该位置 |
| 拖整个文件夹 | 递归扫描支持的格式，导入全部 |

导入时右侧显示进度条，可取消。**大文件导入不能阻塞界面。**

支持格式（首版）：

- 视频：MP4、MOV、MKV、WebM、AVI
- 音频：MP3、WAV、AAC、FLAC
- 图片：PNG、JPG、JPEG、BMP、TIFF、WebP
- 序列图片：支持按文件名序号识别为序列

### A3 素材操作

右键菜单：在源监视器打开、插入到时间线、覆盖到时间线、重命名、重新链接（素材被移动时）、从项目移除、在文件管理器中显示。

**「从项目移除」不删磁盘文件**，只解除引用。删除磁盘文件必须走单独一项，且要二次确认。

## 四、模块 B：监视器

### B1 两个监视器

- **源监视器（Source）**：看素材本身，设定入点出点
- **节目监视器（Program）**：看序列的合成结果

两者可在同一个面板内切换标签，也可以并排显示（用户可切）。

### B2 播放控制

播放/暂停、逐帧前进后退、跳到上一剪辑点/下一剪辑点、跳到序列开头/结尾、循环播放、入点出点设置。

快捷键与主流剪辑软件保持一致（空格播放、J K L 变速播放、方向键逐帧）。

### B3 显示辅助

- 分辨率缩放：适应窗口、25%、50%、100%、200%
- 安全框、网格、参考线
- 显示模式：完整、仅 alpha、红绿蓝单通道
- 示波器：波形图、矢量示波器、直方图（可停靠在监视器下方）

### B4 性能要求

- 目标：1080p 25fps 素材在 1080p 序列上**稳定 60fps 预览**
- 达不到时自动降级：先降预览分辨率，再降预览帧率，**最后才降画质**
- 降级状态要在监视器角落显示一个不打扰的提示（如「预览 1/2 分辨率」），不能悄悄降

## 五、模块 C：时间线

### C1 轨道

- 视频轨 V1 到 Vn（默认 3 条，可增）
- 音频轨 A1 到 An（默认 2 条，可增）
- 每轨可：静音、独奏、锁定、隐藏（视频轨）
- 轨道高度可调，可折叠

### C2 片段操作

| 操作 | 交互 |
| --- | --- |
| 选择 | 单击；Ctrl 加选；Shift 范围选；框选 |
| 移动 | 拖动；拖动时显示吸附参考线；按住 Alt 拖动为复制 |
| 修剪 | 拖片段左右边缘；按住 Shift 修剪时不吸附 |
| 切割 | 剃刀工具单击，或在播放头位置按 Ctrl+K 切所有选中轨 |
| 波纹删除 | Shift+Delete，删除后后面的片段前移填补 |
| 变速 | 右键「速度/时长」，或拖动片段上方的速度手柄 |
| 转场 | 从特效面板拖转场到两个片段交界处 |
| 折叠为复合片段 | 选中多个片段，右键「折叠为复合片段」 |

### C3 吸附

吸附对象：其他片段的头尾、播放头、序列入点出点、标记点。

- 默认开启，可一键关闭（工具栏磁铁图标）
- 吸附距离按屏幕像素算（建议 8px），不按时间算，这样缩放时手感一致

### C4 撤销

- 撤销栈**无上限**（受内存约束，但不要设一个很小的固定值）
- Ctrl+Z 撤销，Ctrl+Shift+Z 重做
- 撤销栈全应用共享，剪辑操作与特效操作在同一个历史里（见 [04](04-剪辑与特效融合设计.md) 第四节）
- 历史面板可看完整操作列表，可跳到任意历史点

### C5 标记

- 在时间线上打标记（快捷键 M），可命名、可设颜色
- 标记显示在时间尺上，可作为吸附对象

### C6 录音（用户点名要，不准少）

软件内直接录音，**不需要外部录音软件**。

| 项 | 要求 |
| --- | --- |
| 入口 | 时间线工具栏一个**麦克风按钮**；也可在音频轨右键「在此轨录音」 |
| 输入设备 | 下拉选择系统录音设备，可刷新设备列表 |
| 电平表 | 录音时实时显示输入电平，**过载变红**并提示 |
| 监听 | 可开关耳机监听（避免啸叫，默认关） |
| 录制行为 | 点开始 → 播放头走 → 录进指定音频轨的新片段；可暂停、可停止 |
| 同步 | 录制片段与时间线**帧精确对齐**，音画不漂移 |
| 倒计时 | 开始前可选 3 秒倒计时 |
| 文件 | 录制的音频存进 `上传素材/音乐/`（或用户指定），并成为项目素材 |

> 录音属于**基础能力**，不是附属小功能。剪辑软件不能录音是荒谬的。

## 六、模块 D：效果栈与图层树

> **界面里没有节点图，也没有连线。** 特效以「**效果栈**」表达：选中一个片段，右侧属性面板就出现它的效果栈；效果是纵向排列的折叠卡片，自上而下按顺序处理画面。同一片段的多个效果组成一条处理链——用户看到的只有卡片，不需要连任何线。**内部求值仍然是图（DAG），界面是层**（见 [04](04-剪辑与特效融合设计.md) 第五节）。

### D1 基本操作

| 操作 | 交互 |
| --- | --- |
| 添加效果 | 从特效面板把效果**拖到片段上**；或在效果栈顶部点「+」呼出中文搜索添加 |
| 调整顺序 | 在效果栈里**上下拖动**卡片，改变处理顺序（越靠上越先处理） |
| 旁路 | 每张卡片标题栏有一个**开关**，关掉即旁路该效果（画面直通，卡片保留） |
| 删除 | 卡片右侧的删除按钮，或在卡片上右键「移除效果」 |
| 选中 | 单击卡片标题栏选中该效果，面板下半部显示它的参数 |
| 折叠 / 展开 | 点卡片标题栏左侧的三角，折叠后只显示效果名与开关 |
| 打关键帧 | 参数行左侧的**秒表**图标（见 E2） |
| 折叠为复合片段 | 选中多个片段，右键「折叠为复合片段」 |
| 进入复合片段 | 双击 |

**效果栈的作用范围有两种，机制相同：**

- 选中**片段**时，效果栈只作用于这个片段的画面
- 不选任何片段（选中**序列**）时，效果栈作用于整条序列的合成结果

### D2 效果卡片外观

每张效果卡片显示：效果名（中文）、类型图标、旁路开关、折叠三角、拖动手柄、关键帧标记（参数打了关键帧时显示小图标）。展开后下面列出该效果的全部参数行。

**效果名用中文**（如「模糊」「调色」「色键」），不显示英文类名。

### D3 首版效果清单

**输入 / 生成类**

| 效果 | 说明 |
| --- | --- |
| 序列 | 代表整条时间线的输出 |
| 片段 | 代表时间线上的一个片段 |
| 颜色 | 生成纯色画面 |
| 文字 | 生成文字层 |
| 图片 | 引用素材箱里的图片 |

**变换类**

| 效果 | 参数 |
| --- | --- |
| 变换 | 位置、缩放、旋转、锚点、倾斜 |
| 裁剪 | 上下左右边界 |
| 镜像 | 水平/垂直 |

**颜色类**

| 效果 | 参数 |
| --- | --- |
| 调色 | 曝光、对比度、饱和度、色温、色调、高光、阴影 |
| 曲线 | RGB 与单通道曲线 |
| LUT | 载入 .cube 文件，强度 |
| 单色 | 转灰度、着色 |

**滤镜类**

| 效果 | 参数 |
| --- | --- |
| 模糊 | 半径、类型（高斯/方框/方向） |
| 锐化 | 强度、半径 |
| 发光 | 阈值、半径、强度 |
| 噪点 | 强度、缩放、动画速度 |
| 马赛克 | 块大小 |

**抠像类**（简单易用是重点，用户点名要）

| 效果 | 参数 |
| --- | --- |
| **色度抠图（色键）** | **吸管取色**、容差、边缘羽化、溢色抑制、去杂边、边缘收缩/扩展、视图切换（结果/遮罩/原图） |

> 抠像必须**一眼就会用**：默认给一个「取色滴管 + 容差滑块」，选完即出结果，不需要理解节点或通道。进阶参数（溢色抑制、边缘细化）收在「高级」折叠区里，不吓人。

**蒙版 / 形状遮罩**（合成基本功，不准少）

| 效果 | 参数 |
| --- | --- |
| **钢笔蒙版** | 路径点、贝塞尔切线、闭合、反转、羽化、扩展、不透明度 |
| **矩形 / 椭圆蒙版** | 位置、尺寸、圆角、旋转、反转、羽化、扩展 |
| **蒙版跟踪** | 依附 2D 追踪轨迹，蒙版跟着动（见 [10](10-特效合成与空间识别.md) 4.1） |

> 一个图层可挂**多个蒙版**，可设相加 / 相减 / 相交 / 排除；蒙版的每个路径点与参数都能打关键帧。

**粒子类**（用户点名要，不准少）

| 效果 | 参数 |
| --- | --- |
| **粒子系统** | 发射器（点/线/区域/形状/图层）、发射速率、寿命、初速度与方向、重力、阻力、湍流、尺寸随生命周期曲线、透明度随生命周期曲线、颜色随生命周期、旋转与角速度、贴图（用哪张图当粒子）、混合模式、最大粒子数 |

> 粒子参数要能**实时预览**，拖滑块即见效果；生命周期曲线用**曲线编辑器**编辑（与关键帧同一套编辑器，见 E3）。首版求「稳、快、够用」，不做流体/刚体解算。

**合成 / 图层类**

| 效果 | 参数 |
| --- | --- |
| 混合 | 混合模式、不透明度 |
| 遮罩 | 遮罩输入、反转、羽化 |
| 合并 | 两个输入相加/相减/取最大 |

**空间追踪类**（特效合成的地基，见 [10](10-特效合成与空间识别.md) 第四、五节）

| 效果 | 参数 |
| --- | --- |
| 特征点追踪 | 追踪区域、特征数量、最小间距、精度（快/标准/精） |
| 相机解算 | 求解器（交互式 / COLMAP）、焦距、畸变、关键帧间隔、重投影误差显示 |
| 三维场景 | 点云输入、坐标原点、缩放参考 |
| 三维平面 | 依附平面（三轨迹点）、尺寸、朝向 |
| 三维文字 | 文字、字体、挤出厚度、材质色 |
| 点云 | 输入点云、点大小、着色模式 |
| **摄像机** | 焦距/视场角、景深（光圈/对焦距离）、运动模糊（快门角度）、多机位切换；见 [09](09-3D摄像机与素材库.md) 的摄像机参数表 |
| **2D→3D 转换** | 模式（相机反投 / 深度分层）、深度来源、分层数、视差强度；把平面视频变成可摆三维元素的空间，见 [10](10-特效合成与空间识别.md) 4.3 |

**输出类**

| 效果 | 说明 |
| --- | --- |
| 输出 | 整条效果栈的终点，送到监视器 |

**版本规划：** 首版（M2）先上 **27 个效果**（输入 / 变换 / 颜色 / 滤镜 / **抠像** / **蒙版** / **粒子** / 合成 / 输出 九类）+ **关键帧引擎与曲线编辑器**（所有参数可打帧，见 E2 / E3）。**空间追踪类 8 个**（含摄像机与 2D→3D 转换）留到 **M5 空间识别**里程碑（见 [08](08-里程碑与验收.md)）。够用，不要贪多。

> **不可缺清单（用户点名）：** 关键帧、曲线编辑器、**粒子系统**、**录音**、**蒙版**、**色度抠图**——这六样一个都不准少。关键帧与曲线编辑器是骨架，粒子与蒙版在 M2 上，**录音**在 M1 上，**色度抠图**在 M2 上。

> **注意：** 早期文档里的「液态 / 流体类」效果（溶解、熔化变形、液态置换、液态金属、流体）**已全部删除**。那是把一次语音识别错误当成需求写进来的，用户已澄清 Reelix 没有流体/液态这回事，详见 [10](10-特效合成与空间识别.md) 第〇节。

## 七、模块 E：属性面板

### E1 内容随选中变化

| 选中对象 | 面板显示 |
| --- | --- |
| 时间线上的片段 | 变换、不透明度、速度、音频音量、混合模式，以及**效果栈**（该片段上的全部效果） |
| 效果栈里的某个效果 | 该效果的全部参数（与内置属性分区显示在同一个面板里） |
| 复合片段 | 它的输出参数 |
| 什么都没选 | 序列设置（分辨率、帧率、色彩空间） |

### E2 关键帧

每个数值参数右侧有一个**秒表图标**：

- 点一下 → 在当前播放头位置打第一个关键帧，该参数进入「已激活关键帧」状态，图标变实心
- 已激活状态下，改参数值 → 在播放头位置自动打关键帧
- 再点一下 → 取消激活，**已打的关键帧保留**（不删除），只是不再自动记录
- 右键秒表 → 菜单：删除此参数所有关键帧、跳到上一个/下一个关键帧

### E3 曲线编辑器

从任何参数都能唤起（点参数右侧的曲线图标）。

- 横轴时间，纵轴参数值
- 关键帧可拖动，可框选多个一起拖
- 贝塞尔手柄：拖动手柄调缓动
- 预设：线性、缓入、缓出、缓入缓出、弹跳、回弹
- 可复制一个参数的曲线粘贴到另一个参数（要求值域兼容）

## 十、状态边界与文案规范

### 10.1 空状态

| 场景 | 文案 |
| --- | --- |
| 项目没有素材 | 「还没有素材」+ 副文案「把视频拖到这里，或者点下面的按钮导入」+ 导入按钮 |
| 时间线为空 | 「时间线是空的」+ 副文案「从素材箱把素材拖到轨道上」 |
| 效果栈为空 | 「还没有特效」+ 副文案「从效果库拖一个效果到这里，或点「+ 添加效果」」 |

### 10.2 加载与进度

- 超过 200ms 的操作必须有进度反馈
- 超过 2 秒的操作必须有进度条 + 可取消
- 超过 10 秒的操作必须有进度条 + 预计剩余时间 + 可取消
- 进度文案用动词，如「正在解码…」「正在渲染第 120 帧…」「正在写入文件…」

### 10.3 错误文案

格式：**发生了什么 + 为什么 + 怎么办**。不要只写「操作失败」。

| 场景 | 文案 |
| --- | --- |
| 素材文件找不到 | 「找不到文件 采访.mp4。它可能被移动或删除了。可以点「重新链接」指定新位置，或者从项目中移除这个素材。」 |
| 解码失败 | 「无法解码 采访.mp4。这个文件的编码格式当前不支持。可以试试先转成 H.264 再导入。」 |
| 导出磁盘空间不足 | 「导出失败：磁盘空间不足。需要约 2.4 GB，当前可用 800 MB。请清理磁盘或换个输出位置。」 |
| GPU 不可用 | 「没有找到可用的显卡加速。已切换到处理器模式，预览可能会变慢。」 |

### 10.4 确认文案

- 破坏性操作必须确认，且确认按钮写明动作，不用「确定」
- 例：「这个操作会删除 3 个片段，不能撤销。」按钮：「删除片段」/「取消」
- 能从回收站恢复的不算破坏性，不弹确认

### 10.5 禁止出现的文案

- 「请稍候」「正在处理，请耐心等待」——没有信息量
- 「操作成功」——成功不需要弹窗，界面变化本身就是反馈
- 「未知错误」——必须给出具体原因
- 任何英文界面字符串
