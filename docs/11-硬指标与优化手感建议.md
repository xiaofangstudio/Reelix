# 11 · 硬指标、优化建议与手感建议

> 本文是 Reelix 的补充文档。硬指标一节给可验收的数字，优化建议一节给性能做法，手感建议一节给交互做法。
> 与 [08-里程碑与验收.md](08-里程碑与验收.md) 冲突时以 `08` 为准；本文只做补充，不推翻已有验收项。

## 一 硬指标

全部为可测量值，不是目标描述。测不出来的一律不算。

| 项 | 指标 | 测法 |
| --- | --- | --- |
| 交付体积 | MSI ≤ **150MB** | `npm run tauri build` 产物 |
| 生态约束 | 除 Reelix 外任何产品 ≤ **112.5MB**（150 × 3/4） | 各产品产物对比 |
| 冷启动 | 空项目双击到界面可见 ≤ 3s | 秒表或 `Measure-Command`，取 10 次中位数 |
| 空闲内存 | 打开空项目 ≤ 600MB 私有工作集 | 任务管理器 |
| 1080p 预览 | 三轨合成 ≥ 60fps | 监视器内置帧率显示 |
| 参数响应 | 拖动滑块到画面更新 ≤ 100ms | 见 `08` M2 验收 |
| 3D 预览 | 三维视图 ≥ 30fps | 帧率显示 |
| 导出速度 | 1080p H.264 ≥ 1.2× 实时 | 3 分钟成片 ≤ 150s |
| 相机解算 | 1080p 30s 素材，交互式 ≤ 30s 出轨迹 | 见 `08` M5 验收 |
| 撤销 | 20 次混合操作可全退回，两个视图同步 | 见 `08` M3 验收 |
| 自动保存 | 间隔 ≤ 90s，崩溃后最多丢 90s | 杀进程实测 |
| 常驻 | 关窗后进程数 **0** | `Get-Process Reelix` |
| 联网 | 除用户主动导入导出外，抓包请求数 **0** | 见 `08` M4 验收 |

体积这一条有两把尺子：150MB 是自身红线，112.5MB 是生态天花板对**其他产品**的约束。Reelix 作为天花板本身不受 3/4 规则限制。

## 二 优化建议

### 2.1 解码与缓存

1. **帧缓存按「时间戳 + 分辨率」双键做 LRU。** 单键缓存会让代理帧把全分辨率帧挤出去，回放时反复重解码。
2. **解码器按分辨率分池。** 4K 与 1080p 混在同一个池里会互相驱逐，切镜头时出现明显卡顿。
3. **缩略图与音频波形用 mmap 加金字塔。** 不要把整个源文件读进内存再抽帧。
4. **硬件解码探测失败要静默回退软解**，只在监视器角落给一次提示，不弹对话框。

### 2.2 合成与求值

5. **脏标记沿内部图反向传播。** 只重算受影响的上游子图，其余节点直接命中缓存。
6. **拖动时切代理分辨率，松手回全分辨率。** 拖动过程按 1/2 或 1/4 分辨率求值，松手后补一帧全分辨率。
7. **关键帧曲线求值结果按帧号缓存。** 同一条曲线在同一帧被多个节点读取时只算一次。
8. **效果输出缓存设上限并允许手动清空。** 缓存无限增长会把内存吃穿，设置面板里给出当前缓存占用。

### 2.3 前端

9. **时间线绘制走 canvas 脏矩形。** 播放头移动只重绘受影响条带，不做全量重绘。
10. **大列表虚拟化。** 素材箱与效果列表超过 200 项时只渲染视口内的行。
11. **拖动期间禁用非必要的 React 重渲染。** 用 `transform` 直接改 DOM，状态在松手时统一提交。
12. **字体子集化在构建期完成。** 运行时不做字形裁剪，不解析整包字体文件。

### 2.4 导出与解算

13. **导出走独立线程池，主线程只更新进度。** 导出期间时间线必须仍可编辑。
14. **COLMAP 走 sidecar 进程。** 崩溃或被强杀时主程序只弹中文提示，不受影响。
15. **自研解算走后台线程加取消令牌。** 追踪全程可取消，取消后界面不假死。
16. **导出与预览共用同一套 WGSL 公式。** 禁止用 WebGL 截屏充当导出路径。

## 三 手感建议

### 3.1 拖动与吸附

1. **参数滑块实时跟手，不设「应用」按钮。** 这是 Reelix 与同类软件拉开差距的地方。
2. **时间线缩放以鼠标位置为锚点**，不以播放头为锚点。缩放后光标下的帧应当保持不动。
3. **吸附触发带宽 6px，命中时画出参考线。** 参考线要在松手后淡出，不残留。
4. **拖动片段时显示入点、出点、时长浮层。** 浮层跟随光标，不与片段重叠。

### 3.2 反馈与可预期

5. **所有耗时操作都有可取消的进度。** 导入、解算、导出、批量转码四类都要有。
6. **进度要给剩余时间，不只给百分比。** 百分比让人焦虑，剩余时间让人安心。
7. **撤销跨视图同步。** 一次 `Ctrl+Z` 要同时回退时间线与效果栈的状态。
8. **面板分隔条拖动时显示像素尺寸提示**，松手后隐藏。
9. **预览性能降级要在监视器角落明确标出当前档位**，不静默降级。

### 3.3 键盘与精度

10. **空格播放暂停，J / K / L 变速，I / O 打入出点。** 与主流剪辑软件一致，不做自创键位。
11. **播放头拖动跟随平滑，松手立即吸附到精确帧。**
12. **逐帧步进用方向键，`Shift` 加速十倍。**
13. **效果搜索框支持中文与拼音首字母。** 输入「模糊」与「mh」都能搜到同一个效果。

### 3.4 错误处理

14. **出错给中文人话。** 写清发生了什么、影响什么、下一步做什么，不给英文堆栈。
15. **追踪失败要给明确指引**，例如「追踪失败，请重新框选特征明显的区域」，不显示重投影误差数字了事。
