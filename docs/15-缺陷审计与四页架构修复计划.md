## 三、四页面架构设计（用户口径，达芬奇式）

页面导航条固定在窗口顶部（顶栏下方），四个页签：**素材 ｜ 剪辑 ｜ 特效 ｜ 导出**。
首次进入落「素材」页；有工程后各页常驻，数据同一份后端工程，切页不丢状态。

### 页 1 · 素材（Media）
- 左侧：素材箱树（视频 / 音频 / 图片 / 字幕 / 序列 五个分类，自动按导入类型归档）
- 主区：缩略图网格（真缩略图），悬停显示时长/分辨率/帧率/编码
- 右侧：选中素材详情（元数据 + 大图预览 + 「重链」「移除」）
- 动作：导入素材（多选）、从素材双击「插入到时间线」（自动落 V/A 轨）
- 空状态：大按钮「导入素材」，支持把文件拖进窗口

### 页 2 · 剪辑（Edit）——内含三个子页签
- **剪辑**（默认）：监视器（上）+ 时间线（下），现有 TimelineView 全量迁入；
  双监视器（源/节目）排 M 后续，先保节目监视器
- **音频**：时间线音频轨高亮 + 音量表 + **录音面板**——选输入设备、
   REC 开始/停止（getUserMedia + MediaRecorder，落 WAV 到工程目录并自动导入为音频素材）、
  录音时画实时电平
- **调色**：监视器 + 色轮/滑块组（曝光/对比/饱和/色温/色调）挂序列级效果栈，
  示波器先给亮度波形一种（后面里程碑补矢量示波器）
- 通用：属性面板（片段速度、不透明度）、快捷键（空格、JKL、I/O、Ctrl+K、Ctrl+Z）

### 页 3 · 特效（Fusion 精神，但无节点连线——红线）
- 左：效果库（按 变换/颜色/滤镜/合成/抠像/蒙版/粒子 分类，中文搜索）
- 中：监视器（与剪辑页共享同一 `request_frame` 链路）
- 右：效果栈（自上而下卡片）+ 参数区 + 「打关键帧」入口
- 下：曲线编辑器（现有 CurveEditorView 迁入，拖关键帧画面即变）
- 拖效果卡片到监视器 = 挂到选中片段；序列级效果单独一栏

### 页 4 · 导出（Deliver）
- 左：导出预设（1080p H.264 / 4K H.264 / 720p 代理，读后端 `export_presets()`）
- 中：导出范围（整条序列 / 入出点之间）、输出路径（系统另存对话框）、
  预计体积
- 右：渲染预览小窗 + 「开始导出」
- 导出中：真进度（当前帧/总帧、ETA、阶段文案）、取消按钮；完成后「打开所在文件夹」
- 底部：导出历史列表

## 五、修复结果记录（同日晚间）

1~6 全部落地，7 在建。要点与偏差：

- **缩略图**：`generate_thumbnail` 改回 PNG 字节（`tauri::ipc::Response`），ffmpeg 真抽帧，
  缓存目录秒级粒度缓存；素材箱对 video/image/imageSequence 取中点帧，加载失败静默回退类型文字。
- **波形**：新后端模块 `media/audio.rs`（`decode_mono` 8kHz 单声道 + `peaks_from_pcm` 峰值桶，
  纯逻辑带单测）；命令 `extract_waveform`；时间线 `ClipWave` 内联 SVG 镜像竖条，
  桶数随缩放防抖 200ms 重取，`pointer-events:none` 不碰交互。
- **导出**：`start_export` 起后台线程，逐帧 plan → decode → composite → RGBA 直灌 ffmpeg
  stdin（h264/h265 + yuv420p + faststart），音频按轨道混成立体声 PCM 第二路输入（AAC 192k），
  真进度/ETA/取消/暂停走 `export://progress`；导出画幅等比收进预设框且**绝不硬放大**。
  复用预览管线前把 `plan_frame` 的画幅参数显式化了（`preview_size` 只归预览管）。
- **录音**：`RecordingPanel`（enumerateDevices + MediaRecorder + AnalyserNode 电平），
  字节交后端 `save_recording` 转 48kHz WAV 后走 `import_media` 全套流程，`placeAssetsOnTimeline` 上 A 轨。
- **四页架构**：store 加 `page`（默认 **素材**，达芬奇口径），TopBar 下方页签条；
  剪辑页内含 剪辑/音频/调色 三个子页签；TopBar 假导出按钮改为跳导出页（死按钮消灭）。
- **验证**：`npx tsc --noEmit` 零错误；`cargo test` 165 过 0 挂（含导出画幅 3 个新测试）。
- **构建**：`cargo clean` 清掉旧路径缓存（项目从桌面搬进 deskbox 后 target 全废），
  release 全量重编中；编完重建桌面快捷方式。

**红线不变**：白+浅绿双色、无紫色、全中文、无 AI/账号/自动更新、不 git 提交推送、特效页无节点连线。
