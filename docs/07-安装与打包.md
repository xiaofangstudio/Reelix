# 07 · 安装与打包

## 一、分发形态

| 项 | 内容 |
| --- | --- |
| 渠道 | **官网**（小方工作室官网），以及 FangBox 生态链下载器 |
| 安装包格式 | **MSI**（WiX） |
| 是否上 GitHub | **上**（Reelix 是创作线产品，源码在 GitHub，但 **GitHub 渠道不提供 MSI**） |
| 安装模式 | `currentUser`（当前用户安装，不需要管理员权限） |
| 自动更新 | **永不自动更新**。装了哪个版本就是哪个版本 |

**体积红线：150MB**（长期沿用，不因功能追加而上调；原为 100MB，已由 [09-3D摄像机与素材库.md](09-3D摄像机与素材库.md) 修订——因为要内置字体库与预设动效）。目标是 60MB 以内。

> **预算里本来就含字体与动效。** 150MB 的构成见 [09](09-3D摄像机与素材库.md) 第一节：主程序 15MB、FFmpeg 35MB、内置字体 40MB（中文子集化）、预设动效/转场/缓动 2MB、LUT 5MB 等，并留 44MB 余量给版本迭代慢慢补。**字体与预设是要打进包的既定内容**，不是「不打」的东西。

> 注意区分：25MB 的红线是给小方**生产力套件**（办公六件套）定的，那些是轻量文档工具。Reelix 是**特效合成软件**，要带 FFmpeg、GPU 着色器、内置字体与预设动效，**150MB** 是它的红线。COLMAP 等重型解算组件走**可选组件**，不计入主包。

## 二、体积控制

Reelix 的体积大头是 FFmpeg 与前端产物。控制手段按收益排序：

| 手段 | 收益 | 说明 |
| --- | --- | --- |
| **FFmpeg 只带需要的编解码器** | 最大 | 自编译时只开 H.264 / HEVC / ProRes / AAC / MP3 / FLAC 相关，关掉全部用不上的。这一条能省几十 MB |
| **界面字体不打包** | 大 | **界面**文字用系统字体栈，Clypra 带的一堆 `@fontsource/*`，**一个都不要**。注意区分：**内容层字体库**（文字层 / 字幕 / 三维文字）是**内置**的，中文子集化后约 40MB，已计入 150MB 红线，见 [09](09-3D摄像机与素材库.md) 第一、三节 |
| **release profile 极限优化** | 中 | 见下方 |
| **图标只留 .ico** | 中 | 删掉 `icon.icns` 与多尺寸 png 集 |
| **前端产物压缩** | 中 | Vite 生产构建 + gzip/brotli 预压缩 |
| **WGSL 着色器内联** | 小 | 编译进二进制，不单独放文件 |
| **不引入组件库** | 中 | Tailwind / shadcn / Radix 全不引 |
| **UPX 压缩（可选）** | 中 | 有杀软误报风险，**默认不开** |

`src-tauri/Cargo.toml` 的 release profile：

```toml
[profile.release]
opt-level = "z"        # 优先体积
lto = true             # 链接时优化
codegen-units = 1      # 最大化优化
panic = "abort"        # 去掉 unwinding 表
strip = true           # 剥离符号
incremental = false
```

## 四、MSI 安装流程

用户拿到的 MSI 双击后，走标准 WiX 流程，六步：

| 步骤 | 界面 | 要点 |
| --- | --- | --- |
| 1 | 欢迎页 | 显示产品名、版本、发行者「小方工作室」 |
| 2 | **选择安装位置** | 默认 `C:\Users\<用户>\AppData\Local\Reelix`，可改。显示所需磁盘空间 |
| 3 | **是否创建快捷方式** | 桌面快捷方式（默认勾选）、开始菜单（默认勾选） |
| 4 | 确认安装 | 汇总用户的选择 |
| 5 | 安装进度 | 进度条 |
| 6 | 完成页 | **勾选「立即启动 Reelix」**（默认勾选），点完成 |

**硬性要求：**

- MSI 必须写**注册表卸载项**，保证能在 Windows「设置 → 应用 → 已安装的应用」里正常卸载
- 卸载时询问是否保留用户配置与项目文件，**默认保留**
- 安装不需要管理员权限（`currentUser` 模式）
- 安装程序全程中文

## 五、首次启动向导

首次启动（或用户从菜单主动唤起）显示三步向导。参考 PyCharm 那种「先稍微设置一下」的感觉。

### 第 1 步：外观

| 项 | 默认 |
| --- | --- |
| 主题 | 浅色（Reelix 的默认） |
| 界面缩放 | 跟随系统 |

三个大按钮式选项：浅色（默认）/ 深色 / 跟随系统。每个选项旁边给一个小预览缩略图。

### 第 2 步：与同系列软件联动

**自动搜索**本机已安装的小方工作室软件，用于后续联动。

搜索来源：

1. 注册表卸载项（`HKLM` 与 `HKCU` 的 `Software\Microsoft\Windows\CurrentVersion\Uninstall`）
2. 常见安装路径扫描（`%LOCALAPPDATA%`、`%PROGRAMFILES%`、`%APPDATA%`）
3. Reelix 自己的已装记录（`%APPDATA%\Reelix\linked.json`）

**界面：**

```
┌────────────────────────────────────────────────────────┐
│  与同系列软件联动                                        │
│                                                        │
│  找到这些软件：                                          │
│  ✓ Strata      0.1.0     C:\Users\...\Strata            │
│  ✓ FangBox     1.0.0     C:\Users\...\FangBox           │
│  ✓ Kinexa      未安装                                    │
│                                                        │
│  没找到你要的？手动指定它的安装文件夹：                    │
│  [ 选择文件夹… ]                                        │
│                                                        │
│              [ 上一步 ]  [ 下一步 ]                      │
└────────────────────────────────────────────────────────┘
```

**手动选择的关键规则：**

- **让用户选「文件夹」，不是选软件的 EXE。** 这是明确要求。
- 选中文件夹后，遍历深度**不超过 3 层**，找出匹配的 exe
- 找到多个候选时列出来让用户确认是哪一个
- 读出版本号（从 exe 的文件版本信息，或同目录的版本文件）
- 记为 `source: "manual"`，与自动检测的 `source: "registry"` / `"scan"` 区分
- 没检测到任何软件时，这一步可以跳过，不阻塞用户

**为什么要联动：** Reelix 与 Strata（位图）、Kinexa（二维动画）、FangBox（分发）之间有素材与工程互操作的可能。首版联动的具体能力后续定义，这里先把「知道对方在哪」这件事做掉。

### 第 3 步：默认设置

| 项 | 默认 |
| --- | --- |
| 缓存目录 | `%LOCALAPPDATA%\Reelix\cache` |
| 缓存上限 | 20 GB |
| 自动保存间隔 | 5 分钟 |

### 向导的硬性要求

- **完全免费，不需要登录账号，不需要联网注册。** 向导里不出现任何登录、注册、激活、订阅的字样
- 全程可以点「跳过」，跳过也能正常用
- 用户之后可以在「设置」里重新打开这个向导

## 六、文件关联

Reelix 注册 `.reelix` 文件关联：

- 双击 `.reelix` 打开 Reelix 并载入该项目
- 图标用 Reelix 的项目图标（不是应用图标）
- 在「设置」里可以取消关联

同时注册的可选关联（默认不开，用户可在设置里开）：

| 扩展名 | 说明 |
| --- | --- |
| `.cube` | LUT 文件 |
| 视频格式（`.mp4` 等） | **默认不关联**，不要抢用户系统里的默认播放器 |

## 七、构建命令

```powershell
# 开发
npm install
npm run tauri dev

# 类型检查
npx tsc --noEmit

# 生产构建（产出 MSI）
npm run tauri build

# 产出位置
# src-tauri/target/release/bundle/msi/Reelix_0.1.0_x64_en-US.msi
```

**构建前必须准备 FFmpeg 动态库**，放在 `src-tauri/ffmpeg/`，并在 `bundle.resources` 里声明。Clypra 的 `scripts/setup-ffmpeg.sh` 与 `scripts/ensure-sidecars.mjs` 是参考实现。
