# 08 · 里程碑与验收

一次只推一个里程碑。每个里程碑必须**全部验收项打勾**才能进下一个。

> **定位说明：** Reelix 是**特效合成软件**（合成优先，剪辑是附属）。因此里程碑的排法是：M1 把附属的剪辑能力打通（因为合成要有素材可摆），M2 起进入**合成主体与关键帧骨架**，M3 立起**融合 + 预设 + 复合片段**，M5 是**空间识别**（含摄像机、2D→3D 转换）这块特效合成的核心地基。完整背景读 [10-特效合成与空间识别.md](10-特效合成与空间识别.md)。
>
> **注意：** 早期文档里的 **M6「流体与稠密重建」已删除**——用户澄清「流体/液态」是语音识别错误，Reelix 没有这个需求。稠密重建（MVS）作为空间识别的可选深化，并入 M5 的可选部分。

## M3 · 融合成立 + 预设 + 复合片段（关键里程碑）

**目标：** 时间线与图层/效果栈双向联动，关键帧共享；**预设特效与复合片段可用**。**这一关不过，整个产品方向要重新讨论。**

### 任务

- [ ] 前端：时间线轨道与效果栈做成同一份数据的两种看法，选中态实时同步
- [ ] 前端：`selectionStore` 统一两个视图的选中态
- [ ] **联动 A**：时间线点片段 → 属性面板定位并展开对应效果栈
- [ ] **联动 B**：效果栈点某效果 → 时间线定位到对应片段，播放头跳到入点
- [ ] **联动 C**：效果旁路 → 时间线片段视觉上标记「已旁路」
- [ ] 前端：曲线编辑器组件（拖动关键帧、贝塞尔手柄、缓动预设、多曲线同屏）
- [ ] **共享关键帧**：片段参数、效果参数、摄像机参数用同一套引擎、同一个编辑器
- [ ] 前端：打了关键帧的参数在时间线上生成参数曲线轨道
- [ ] **复合片段（预合成）**：折叠、进入、返回、面包屑导航
- [ ] 复合片段：嵌套深度上限 8 层
- [ ] **预设特效**：保存为预设 / 套用 / 重命名 / 删除 / 分组（存进 `上传素材/预设/`）
- [ ] **素材文件夹结构**：首启创建「上传素材」目录树（音效/音乐/图像/视频/字体/预设/工程），素材箱显示文件夹树并自动刷新
- [ ] 共享撤销栈：剪辑操作与特效操作在同一个历史里
- [ ] **2D 特征点追踪**：`features2d` 接入（OpenCV），框选区域后出轨迹点与轨迹线
- [ ] **视频稳定**：把追踪结果反过来用，自动计算补偿变换，画面抖动明显减小

## M5 · 空间识别（特效合成的地基）

**目标：** 从实拍里解出摄像机与场景三维结构，让三维元素能焊进画面。这是用户点名「最基础」的能力。

> 完整方案见 [10-特效合成与空间识别.md](10-特效合成与空间识别.md)。

### 任务

- [ ] Rust 侧：相机解算（五点法 / EPnP 初始位姿 + 光束法平差），矩阵用 `nalgebra`
- [ ] Rust 侧：点三角化 → 稀疏点云
- [ ] Rust 侧：统一相机数据格式（JSON），three.js 与 Rust 两侧共用
- [ ] Rust 侧：**COLMAP sidecar 调用**（独立进程、进度回传、可取消、可强杀）
- [ ] 前端：追踪面板（框选区域、开始/停止、进度、重投影误差显示）
- [ ] 前端：3D 视图里的相机轨迹球与点云显示（复用 [09](09-3D摄像机与素材库.md) 的 three.js 视图）
- [ ] 前端：节点「特征点追踪」「相机解算」「三维场景」「三维平面」「三维文字」「点云」
- [ ] 前端：场景缩放参考（选两条轨迹定义实际距离）
- [ ] 求解器可切换：交互式 ↔ COLMAP

### 验收

## 风险与应对

| 风险 | 触发信号 | 应对 |
| --- | --- | --- |
| **融合模型方向错** | M3 验收有任一条过不了 | **停下，不要用界面补丁糊**。回头改数据模型，重做 M3 |
| **预览性能不达标** | 拖动参数时画面延迟 > 300ms | 上代理分辨率、帧缓存、脏标记求值三件套；仍不达标就砍掉首版的部分重特效节点 |
| **范围失控** | 想在 M1 就做相机解算 | 严格按里程碑。**M0 之前不碰导出，M3 之前不碰相机解算，M5 之前不碰稠密重建（MVS）** |
| **GPL 污染** | 新引入的依赖许可不明 | 立即移除，走 [06](06-参考项目与许可边界.md) 白名单 |
| **把 Clypra 的遥测带进来** | 代码里出现 `telemetry` / `report` / `upload` | 立即删除。**Reelix 绝不上报任何数据** |
| **把 Clypra 的 AI 模块带进来** | 代码里出现 `ai/` / `mediapipe` / `model_manager` | 立即删除。**Reelix 不带任何 AI** |
| **把追踪做成了 AI** | 代码里出现任何模型文件 / 推理 / 联网下载权重 | 立即改回几何算法（特征匹配 + 平差）。**追踪与解算不接模型、不联网** |
| **拿 WebGL 截屏当导出** | 导出模块里出现 `toDataURL` / `canvas` 截屏 | 立即改回 wgpu + WGSL 重算。**3D 视图只作预览** |
| **解算把主程序拖死** | 追踪时界面卡住、无法取消 | COLMAP 走 sidecar，自研解算走后台线程 + 可取消 + 进度回传 |
| **配色跑偏** | 界面上出现紫色或第二强调色 | 立即改回**浅绿 `#26734f`**（`--rl-accent`）。这是用户明确发过火的事 |
| **定位表述跑偏** | 文档或菜单把 Reelix 说成"剪辑软件" | 立即改回**特效合成软件（合成优先）**。用户明确纠正过 |
| **意外提交到远程** | `git status` 显示有远程 | 立即停下，报告用户。**绝不允许推送** |
