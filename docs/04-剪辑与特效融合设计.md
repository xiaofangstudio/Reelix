# 04 · 剪辑与特效融合设计

这份文档是 Reelix 的**核心设计**。整个产品能不能立住，就看这里的设计对不对。

> **⚠️ 主次必须先说清（用户明确纠正）：** Reelix 是**特效合成软件**，不是剪辑软件。本文档标题里的「剪辑与特效」不要误读成「两者平级」——**合成是主体，剪辑是附属**。所以下文的排序是：以**图层 + 效果栈**作为合成的表达方式（用户可见的界面模型），把**时间线轨道**当作同一份数据的另一种看法挂上去（剪辑的位置）。**内部求值仍然是图（DAG），界面是层。** 这个方向与 [10-特效合成与空间识别.md](10-特效合成与空间识别.md) 的定位修正一致。

---

## 一、问题的本质

After Effects 和 Premiere 之所以是两个软件，不是因为 Adobe 做不出来一个，而是因为**它们是两套不同的心智模型**：

| | 合成（After Effects） | 剪辑（Premiere） |
| --- | --- | --- |
| 基本单位 | 图层 / 节点（Layer / Node） | 片段（Clip） |
| 组织方式 | 按依赖关系连接成图 | 沿时间轴线性排列 |
| 主要操作 | 连接、调参、混合 | 排序、修剪、拼接 |
| 时间概念 | 每个合成有自己的局部时间 | 全局时间轴，一个绝对时刻 |
| 核心参数 | 输入、输出、混合模式 | 入点、出点、轨道 |

这两套模型**不能简单叠加**。这就是为什么那些「把剪辑器和合成器放进同一个窗口」的尝试都失败了——两个面板并排，模型还是两套，用户还是要在两个心智之间切换。

## 二、Reelix 的答案：一套数据，两种看法：时间线轨道 + 效果栈

### 2.1 统一数据模型

**整个项目只有一份数据模型。** 时间线上的片段、片段上的效果栈、序列级的调整，全部挂在同一份模型上，没有第二套。

```
序列
 └─ 轨道 V1 / V2 / A1 …
     └─ 片段（对素材的一次引用）
         └─ 效果栈：效果 1 → 效果 2 → 效果 3 …（纵向折叠卡片，自上而下按顺序处理）
```

关键点：**特效不再是连线，而是挂在片段（或序列）上的一摞卡片。** 选中一个片段，右侧属性面板就出现它的效果栈。

特效因此自然长出来：

- **给某个片段加特效** → 把效果拖到那个片段上，效果进入该片段的效果栈。它只处理这一个片段的画面。
- **给整条序列加特效** → 不选任何片段（选中序列），效果加到序列的效果栈，作用于整条序列的合成结果。
- **做一个预合成** → 把一个或多个片段折叠成复合片段，它像普通片段一样放到时间线上，内部保留原片段与效果栈。

**三种特效位置，同一套机制。** 用户不需要知道「这是片段级还是序列级」，他只需要知道「我把这个效果拖到了哪里」。

> **内部是图，界面是层。** 效果栈在内部仍被编译成一张有向无环图（DAG）来求值（见第五节），但用户看到的永远是纵向的效果卡片，而不是节点与连线。

### 2.2 两种看法：时间线轨道 + 效果栈

同一份数据，两种看法：

| | 时间线轨道（Timeline） | 效果栈（Effect Stack） |
| --- | --- | --- |
| 排列方式 | 按时间轴水平排布，垂直分轨 | 纵向折叠卡片，自上而下 |
| 适合 | 管顺序、时长、拼接 | 管处理链、顺序、混合 |
| 看到的是 | 何时 | 如何 |
| 位置 | 窗口下半区，标签页「时间线」（默认） | 右侧属性面板内（300px），随选中片段出现 |

两种看法**不是两个数据副本**，是同一份数据的两种渲染。改任何一个，另一个立刻反映。

### 2.3 双向联动（这是「贴身融合」的具体含义）

| 用户动作 | 另一个位置的反应 |
| --- | --- |
| 在时间线上点选一个片段 | 属性面板切到该片段，显示它的效果栈并高亮 |
| 在效果栈里点选一个效果 | 时间线自动滚动到对应片段位置，选中它，并把播放头跳到片段入点 |
| 在时间线上拖动片段改变位置 | 效果栈不变（效果顺序是用户排的，不随时间变） |
| 在效果栈里关掉一个效果的开关（旁路） | 时间线上对应片段出现「已旁路」标记，画面立刻直通，但片段本身不动 |
| 在时间线上删除一个片段 | 该片段的效果栈一并消失，可撤销 |

**判据：** 如果用户需要手动在两个位置之间「同步」或「刷新」，那就是做错了。联动必须是即时的、不需要用户操作的。

## 三、三层编辑层级

融合之后，用户面对的其实是三个层级。这三层是**并列的视图**，不是嵌套的菜单。

### 第一层：剪辑层（Cut）

管「什么在什么时候出现」。

- 时间线上排列片段
- 修剪入点出点
- 切割、删除、波纹删除
- 多轨叠放
- 转场
- 变速

这一层的心智模型和 Premiere 一致，用户不需要重新学。

### 第二层：合成层（Compose）

管「画面被怎么处理」。

- 把效果拖到片段上，形成纵向的效果栈
- 混合模式、透明度
- 调色、色键、变换、模糊、发光
- 多层叠加、遮罩与合并（一个画面分成多层处理再合回来）

这一层的心智模型和 After Effects 的效果堆栈一致。

### 第三层：动画层（Animate）

管「参数随时间怎么变」。**这一层同时服务于上面两层，这就是融合点。**

- 任何数值参数都能打关键帧
- 片段的透明度能打关键帧 → 剪辑层的参数
- 效果的模糊半径能打关键帧 → 合成层的参数
- 用的是**同一套曲线引擎、同一个曲线编辑器、同一套缓动预设**

**具体含义：** 用户在时间线上选中一个片段，点开属性面板，把「透明度」的秒表图标点亮，打两个关键帧——这时效果栈里那个参数行旁会出现一个小的关键帧标记。反过来，用户在效果栈里给某个效果的「半径」打关键帧，时间线上的片段轨道下方会出现一条参数曲线轨道。

**一套关键帧，两处可见。** 这是「一体」最直观的体现，也是最难做对的地方。

## 四、共享的底层设施

融合不只是界面上的事，底下这几套东西必须是真的只有一份：

| 设施 | 说明 |
| --- | --- |
| **一套关键帧引擎** | 时间 → 值 的求值。片段参数、效果参数、序列参数全部走它。不要出现「剪辑用的关键帧」和「合成用的关键帧」两套实现 |
| **一套曲线编辑器** | 贝塞尔手柄、缓动预设、曲线复制粘贴。同一个组件，从任何参数都能唤起 |
| **一套撤销栈** | 剪辑操作与特效操作在同一个历史里。用户按一次 Ctrl+Z，撤销的是他上一次做的任何事，不管那件事属于哪一层 |
| **一套时间模型** | 全局时间轴是唯一权威。序列在求值时把全局时间映射成局部时间 |
| **一套色彩管线** | 从素材解码到最终输出，色彩空间转换只有一条路径。剪辑层看到的颜色和合成层看到的颜色必须一致 |
| **一套帧缓存** | 缓存键是「效果节点 + 时间 + 参数哈希」。剪辑层和合成层共用同一个缓存，不重复算 |

## 五、求值模型

借鉴 Gaffer 的**延迟求值（deferred evaluation）**思路。

> **内部是图，界面是层。** 本节描述的是内部求值机制。用户界面里没有节点、没有连线——用户看到的是时间线轨道与效果栈；系统在内部把效果栈编译成一张 DAG 来求值。这一节的模型**保持不变**，只是它不再对用户可见。

### 5.1 原则

**不主动算，被问才算。** 监视器要第 120 帧，就从输出节点反向拉取：问它的输入要第 120 帧，输入再问它的输入。拉到素材节点为止，然后正向算回来。

好处：只算真正被看到的东西。用户在片段上叠了二十个效果，但监视器只显示最终输出，那些不参与最终画面的分支，一个像素都不算。

### 5.2 脏标记

每个节点维护一个「脏」标志。以下情况会标脏：

- 节点自身的参数被改了 → 标脏自己
- 上游节点的输出变了 → 标脏自己和所有下游
- 时间变了 → 标脏所有时间相关节点（如果参数没打关键帧，其实可以不脏，这是优化点）

被标脏的节点，下次被问的时候重算；不脏的节点，直接从缓存拿。

### 5.3 多线程

求值调度器把可以并行的节点分到线程池。判定并行很简单：一个节点只有在它所有输入都算完之后才能算。经典的任务图调度。

**不要用一把大锁。** 每个节点的缓存槽独立加锁，用无锁队列传递就绪任务。

### 5.4 缓存策略

| 缓存 | 内容 | 淘汰策略 |
| --- | --- | --- |
| 解码帧缓存 | 从素材解出来的原始帧 | LRU，按内存占用限制 |
| 节点输出缓存 | 节点算完的中间结果 | LRU，按显存/内存占用限制 |
| 缩略图 / 胶片带 | 时间线上的小图预览 | 落盘，按项目缓存目录管理 |
| 波形数据 | 音频峰值与 RMS | 落盘，与素材文件绑定 |

缓存要有上限，且上限要可配。**不允许无限增长**，用户的磁盘不是我们的。

## 六、复合片段（预合成）

对应 After Effects 的「预合成」与 Gaffer 的「Box / Reference」。

**做法：** 选中一组片段（或一个片段及其效果栈），折叠成一个复合片段。它对外就是一个普通片段，内部保留原来的片段与效果栈。

**关键规则：**

1. 复合片段可以嵌套，但要限制嵌套深度（建议上限 8 层），超过就警告。
2. 双击复合片段进入内部编辑，界面顶部显示面包屑导航（`主序列 › 复合片段 A › 复合片段 B`）。
3. 复合片段内部的时间可以是**独立的**，也可以**跟随外部**。默认独立，用户可以切成跟随。
4. 复合片段在时间线上就是一个普通片段，可以修剪、可以加特效、可以再折叠。

## 七、这个设计的验收标准

M3 结束时，用下面这几条检验融合是否真的做到了。任何一条不通过，说明融合没做对，必须回头改模型，**不允许用「界面补丁」糊过去**。

- [ ] 新建一个项目，导入两段视频，拖到时间线上，能连续播放
- [ ] 给第一个片段加一个「模糊」效果，拖动半径滑块，监视器实时变化，不需要点任何「应用」按钮
- [ ] 给整条序列加一个「调色」效果，两个片段都受影响
- [ ] 给第一个片段的透明度打三个关键帧，曲线编辑器能打开、能拖动贝塞尔手柄、能改缓动
- [ ] 给模糊效果的半径打两个关键帧，**在同一个曲线编辑器里**能编辑，且时间线上出现对应参数轨道
- [ ] 在时间线上点第二个片段，属性面板自动切到它的效果栈并高亮
- [ ] 在效果栈里点「调色」效果，时间线自动定位到对应片段位置
- [ ] 把模糊效果的开关关掉（旁路），画面恢复未模糊，时间线上的片段位置与长度不变
- [ ] 把两个片段折成一个复合片段，再把它拖到另一条轨道上，能正常播放
- [ ] 双击复合片段进入内部编辑，面包屑导航正确，返回后状态正确
- [ ] 连续做二十次剪辑与特效的混合操作，按二十次 Ctrl+Z，**能一路退回初始状态**，且每次撤销都反映在时间线轨道与效果栈上
