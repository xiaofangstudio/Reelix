# 🎬 Reelix

> 小方工作室出品 ｜ Windows 桌面 ｜ MIT ｜ 完全免费

**特效合成软件，剪辑是它的附属能力。**

做合成总要摆镜头顺序，所以时间线直接长在里面，不用再开第二个软件。

## 📦 下载就能用

不用装、不用编译、不用配环境。**下载仓库 → 解压 → 双击 `Reelix.lnk`。**

根目录里放的就是打包好的那份：

| 文件 / 目录 | 是什么 |
| --- | --- |
| `Reelix.exe` | 主程序，双击就开 |
| `Reelix.lnk` | 快捷方式，图标好看一点，指向同目录的 exe |
| `ffmpeg/` | 全套解码运行时，已经在仓库里备好，**不用自己找 ffmpeg** |
| `assets/` | 字体与缓动预设 |
| `scaffold/` | 完整源码，想自己构建的往下看 |

目前还没做安装包，所以走「绿色版」路线：解压到哪就在哪跑，换机器直接拷贝整个文件夹。

## ✨ 现在支持的全部功能

### 🗂️ 四个页面，一条流水线

| 页面 | 能干什么 |
| --- | --- |
| 🗂️ 素材 | 素材箱铺满整页，导入、整理、看缩略图、建素材箱；带声音的视频自动拆成「画面 + 声音」并粘在一起 |
| ✂️ 剪辑 | 上半区素材箱 · 监视器 · 属性面板，下半区多轨时间线 + 调色台；关键帧曲线在轨道下方就地展开；另有「音频」子页签 |
| 🧪 特效 | 停靠式工作区：拖分隔条、页签组、右侧可折叠面板栈，35 个面板随便摆，内置 15 套工作区预设 |
| 📤 导出 | 左边选预设，右边走「序列摘要 → 输出设置 → 进度」；整条序列或从播放头到结尾都行，进度能暂停 / 继续 |

| 分类 | 效果 |
| --- | --- |
| 输入 | 序列、片段、颜色、文字、图片 |
| 变换 | 变换、裁剪、镜像 |
| 颜色 | 调色、曲线、LUT、单色 |
| 调色 | 色轮、色阶 |
| 抠像 | 色度抠图 |
| 生成 | 渐变、圆、棋盘、网格 |
| 风格化 | 查找边缘、浮雕、色调分离 |
| GPU | GPU 调色、GPU LUT |
| 滤镜 | 模糊、锐化、发光、噪点、马赛克 |
| 合成 | 混合、遮罩、合并、不透明度 |

另外还有三个结构节点：**3D 合成、摄像机、复合片段**。序列、片段、输出是骨架节点，不出现在「+ 效果」菜单里。

### 🎨 调色台

- **三个色轮**：阴影 / 中间调 / 高光，点着盘拖，直接改 RGB 通道偏移
- **色阶**：黑白场、中间调 gamma、输出黑白
- **快捷调节**：曝光、对比、饱和、色温、色调、高光、阴影
- **示波器**：从监视器当前帧实时统计 RGB 波形，自绘
- **颜色占比**：色相环 12 桶，一眼看出这一帧偏什么色
- **只对画面生效**：选音频轨、摄像机轨的片段会显示引导文案，不给调色控件

### 🧩 特效页：35 个面板 + 15 套工作区

面板能开能关、能拖能叠、能拆成浮动组，布局自动记住。

- **15 套工作区**：Default、Standard、Small Screen、Animation、Effects、Motion Tracking、Paint、Text、Minimal、All Panels、Review、Learn、Essential Graphics、Color、Undocked Panels
- **接了真数据的面板**：项目、效果控件、合成、图层、时间线、信息、音频、预览、效果预设、属性、字符、段落、对齐、基本图形、历史、渲染队列、素材箱、媒体浏览器、元数据、3D 空间识别
- **还没做的面板**（标记、示波器、跟踪器、摇摆器、平滑器、画笔、流程图、脚本控制台、内容识别填充等）：老老实实写一行说明，**不放假按钮**。

### ✂️ 时间线能做的事

- 多轨：视频轨、音频轨、字幕轨、摄像机轨，V/A 自动编号，分区线可拖
- 拖入素材、移动、裁剪两头、切割、波纹删除、复制粘贴
- 片段启用 / 停用、上色标签、改速度、音视频链接 / 取消链接
- 转场（推 / 拉 / 线性擦除 / 径向擦除 / 百叶窗 / 交叉缩放）、音频淡入淡出
- 标记增删与跳转、裁剪到播放头 / 移到播放头
- 吸附播放头、缩放到序列、逐帧步进、拖到边缘自动滚动
- 编组（复合片段）与进入 / 退出复合
- 轨道小眼睛、轨道颜色标识
- 底部页签一键切到调色台

### 🔑 关键帧：只有一套

片段参数和效果参数打关键帧，走的是**同一个曲线引擎、同一个曲线编辑器、同一份数据**。

- 位置、缩放、旋转、不透明度、锚点、效果参数都能打
- 曲线视图支持贝塞尔切线、切线手柄、32 套缓动预设（含回弹、弹性、过冲）
- 关键帧能拖、能删、能改时间
- 3D 场景里移动对象会同步打关键帧

### 🧮 表达式

属性值可以改写成表达式，走自研引擎：

- 运算：`+ - * / ^ %`、比较、三目
- 函数：`sin cos tan abs floor ceil round sqrt min max clamp random wiggle linear`
- 变量：`time`（秒）、`seed`（稳定随机）
- 角度弧度互换：`degreesToRadians` / `radiansToDegrees`

### 🎙️ 录音、字幕、3D、沉浸

- **麦克风录音**：选设备、看电平、计时，录完直接进素材箱
- **语音转字幕**：auto / 粤语 / 英语 / 日语 / 韩语，生成后可应用成字幕片段，也能逐条改字
- **3D 空间识别**：ffmpeg 抽帧 → 特征提取 → 穷举匹配 → 增量重建 → 解析相机；three.js 显示稀疏点云和相机轨迹，可旋转观察
- **沉浸模式**：在 3D 场景里选中素材右键进入，WASD 移动、空格 / Ctrl 升降，摄像机调视角，移动过程同步打关键帧

### ⚡ 性能与输出

- **GPU 管线**：模糊、GPU 调色、GPU LUT 真显卡计算，失败自动回落 CPU
- **代理媒体**：右键「生成代理媒体」（1/4 画幅、1.5Mbps），大工程剪辑更顺，导出仍用原件
- **渲染队列**：多个序列压队逐项渲染，失败自动停
- **帧缓存**：缓存目录可改，默认上限 20GB，能手动清
- **自动保存**：默认 5 分钟一次，间隔可调，也能关
- **安全框**：监视器左上角一键开，动作 90% / 字幕 80%
- **导出预设**：

| 预设 | 封装 | 视频 | 音频 | 视频码率 |
| --- | --- | --- | --- | --- |
| 1080p H.264 | mp4 | H.264 · 1920×1080 · 30fps | AAC 192kbps | 12 Mbps |
| 4K H.265 | mp4 | H.265 · 3840×2160 · 30fps | AAC 192kbps | 40 Mbps |
| 720p 代理 | mp4 | H.264 · 1280×720 · 30fps | AAC 192kbps | 5 Mbps |

本机 ffmpeg 缺哪个编码器，对应预设就标不可用，不假装能导。

- **EDL 导出**：把时间线导成剪辑表，交给别的流程接着干
- **工程文件**：`.reelix`，本质是个 ZIP 容器，工程、素材索引、效果图一起打包

### 🎨 界面与手感

- 配色重新设计：纯白 + 浅灰 + 鲜亮蓝，长时间看眼睛不累
- 浅色 / 深色主题一键切
- 开场界面、最近工程、新建工程向导、示例工程
- 全中文界面，字号和间距按桌面软件调
- 属性面板滚轮调值，圈数直接写 1X / 2X
- 拖动全部 rAF 节流，时间线拖到边缘自动滚动
- 错误边界兜底，单个面板挂了不拖垮整个应用
- 底部通知条，操作有反馈

### 🤖 自带的 MCP 服务（可选）

`reelix-mcp` 是个独立命令行进程，stdin / stdout 走 JSON-RPC，一共 **26 个工具**：

- **读**：工程、素材、时间线、效果图、节点类型表、单帧求值
- **改**：加 / 删节点、连线、改参数、打关键帧、参数求值
- **剪**：加 / 删 / 移 / 切 / 裁片段、加轨道、转场、字幕、复合片段、3D 变换
- **工程**：新建 / 打开 / 保存、导入素材、探测媒体

不开端口、不联网、不接大模型，也不随安装包分发。

## 🚀 自己构建

### 环境

| 需要 | 说明 |
| --- | --- |
| Windows 10 / 11 | 只做 Windows 桌面 |
| Node.js 18+ | 前端构建，Vite 5 |
| Rust 1.75+ | 后端，Tauri v2 |
| WebView2 | Windows 10 / 11 一般自带 |
| FFmpeg | 自己构建时才需要，放进 `scaffold/src-tauri/ffmpeg/`（根目录的 `ffmpeg/` 是给绿色版用的） |
| COLMAP（可选） | 只有 3D 空间识别用，放到 exe 同级的 `colmap/` 就会自动找到 |

FFmpeg 目录要放齐 `ffmpeg.exe`、`ffprobe.exe` 和 7 个运行时 DLL，同一层。

### 启动

```bash
cd scaffold
npm install

# 只跑前端，浏览器里看界面
npm run dev          # http://localhost:1422

# 跑完整桌面应用
npm run tauri dev
```

### 构建

```bash
npm run typecheck    # TypeScript 类型检查
npm run build        # 前端产物
npm run tauri build  # 打 MSI 安装包
```

## ❓ 常见问题

**双击没反应 / 打开是白屏？**
先确认装了 WebView2（Windows 11 一般自带）。如果是自己构建的，再确认在 `scaffold/` 里跑过 `npm install`。

**导入视频没有画面？**
检查 `ffmpeg/` 里有没有 `ffmpeg.exe`、`ffprobe.exe` 和 7 个 DLL，必须和 exe 在同一层目录结构里。

**3D 空间识别是灰的？**
说明没找到 COLMAP。把它放到 exe 同级的 `colmap/` 目录（往上级目录放也认），重启再试。

**调色台点了没反应？**
要先在时间线上选中视频轨或字幕轨的片段。音频、摄像机轨不参与画面调色，会显示引导文案。

**特效页有些面板是空的？**
那些还没实现，面板会写明情况，不会放点了没反应的假按钮。

**为什么没有节点图？**
节点只在内部求值。界面只给你图层和效果栈，这是刻意设计，不是没做。

**会支持 macOS 吗？**
目前只做 Windows 桌面。
