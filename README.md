# 🎬 Reelix

> 小方工作室出品 ｜ Windows 桌面 ｜ MIT ｜ 完全免费

**特效合成软件，剪辑是它的附属能力。**

主对标 After Effects / Fusion / Nuke，副对标 Premiere。做合成必须能摆镜头顺序，所以剪辑轨道内建在同一个软件里，而不是再开一个。

## ✨ 它能做什么

### 四个页面，一条工作流

| 页面 | 干什么 |
| --- | --- |
| 🗂️ 素材 | 素材箱铺满整页，导入、整理、看缩略图。带声音的视频导入后自动拆成「画面 + 声音」两段并粘在一起 |
| ✂️ 剪辑 | 上半区素材箱 · 监视器 · 属性面板，下半区多轨时间线；关键帧曲线在轨道下方就地展开；另有「音频」子页签 |
| 🧪 特效 | 停靠式工作区：可拖分隔条、页签组、右侧可折叠面板栈，内置 15 套工作区预设 |
| 📤 导出 | 左边预设，右边「序列摘要 → 输出设置 → 进度」；可导出整条序列或从播放头到结尾，进度支持暂停 / 继续 |

> 特效页的面板有 30 多个。有实现的面板接真命令、真数据；暂时没实现的（标记、示波器、跟踪器、摇摆器、平滑器等）只显示说明文字，**不放假按钮**。

### 27 个内置效果，9 大类

| 分类 | 效果 |
| --- | --- |
| 输入 | 序列、片段、颜色、文字、图片 |
| 变换 | 变换、裁剪、镜像 |
| 颜色 | 调色、曲线、LUT、单色 |
| 滤镜 | 模糊、锐化、发光、噪点、马赛克 |
| 抠像 | 色度抠图 |
| 蒙版 | 形状蒙版、钢笔蒙版、蒙版跟踪 |
| 合成 | 混合、遮罩、合并、不透明度 |
| 粒子 | 粒子系统 |
| 输出 | 输出 |

其中**序列、片段、输出**是结构性节点，不出现在「+ 效果」菜单里。

### 关键帧是一套，不是两套

片段参数和效果参数打关键帧，走的是同一个曲线引擎、同一个曲线编辑器。时间线、效果栈、曲线视图看到的是同一份数据。

### 3D 空间识别

用 three.js 显示 COLMAP 算出的稀疏点云和相机轨迹，可以旋转观察。后端流水线全在本机：

**ffmpeg 抽帧 → 特征提取 → 穷举匹配 → 增量重建 → 解析相机**

COLMAP 组件缺失时，只有这一条链路不可用，不影响剪辑、特效和导出。

### 导出预设

| 预设 | 封装 | 视频 | 音频 | 视频码率 |
| --- | --- | --- | --- | --- |
| 1080p H.264 | mp4 | H.264 · 1920×1080 · 30fps | AAC 192kbps | 12 Mbps |
| 4K H.265 | mp4 | H.265 · 3840×2160 · 30fps | AAC 192kbps | 40 Mbps |
| 720p 代理 | mp4 | H.264 · 1280×720 · 30fps | AAC 192kbps | 5 Mbps |

本机 ffmpeg 缺哪个编码器，对应的预设会标成不可用，不会假装能导。

### 自带的 MCP 服务（可选）

`reelix-mcp` 是个独立命令行进程，stdin / stdout 走 JSON-RPC，共 16 个工具：读工程、读素材、读时间线、读效果图，加节点、连线、改参数、打关键帧、求值，以及新建 / 打开 / 保存工程、导入和探测媒体。

不开端口、不联网、不接大模型，也不随安装包分发。

## 🚀 怎么跑起来

### 环境

| 需要 | 说明 |
| --- | --- |
| Windows 10 / 11 | 只做 Windows 桌面 |
| Node.js 18+ | 前端构建，Vite 5 |
| Rust 1.75+ | 后端，Tauri v2 |
| WebView2 | Windows 10 / 11 一般已自带 |
| FFmpeg | 仓库不收二进制，需自备后放进 `scaffold/src-tauri/ffmpeg/` |
| COLMAP（可选） | 只有 3D 空间识别需要，开发时放到仓库根目录 `reference/tracking/colmap-bin/` |

FFmpeg 目录需要 `ffmpeg.exe`、`ffprobe.exe` 和 7 个运行时 DLL，放在同一层。

### 启动

```bash
cd scaffold
npm install

# 只跑前端，在浏览器里看界面
npm run dev          # http://localhost:1422

# 跑完整桌面应用
npm run tauri dev
```

### 构建

```bash
npm run typecheck    # TypeScript 类型检查
npm run build        # 前端产物
npm run tauri build  # 打 MSI 安装包
```

## ❓ 常见问题

**打开是白屏 / 窗口起不来？**
先确认装了 WebView2，然后在 `scaffold/` 里执行过 `npm install`。

**导入视频没有画面？**
检查 `scaffold/src-tauri/ffmpeg/` 是否放齐了 `ffmpeg.exe`、`ffprobe.exe` 和 7 个 DLL。

**3D 空间识别不可用？**
说明没找到 COLMAP。开发时把它放到 `reference/tracking/colmap-bin/`，重启应用再试。

**特效页有些面板是空的？**
那些功能还没实现，面板会写明情况，不会放一个点了没反应的假按钮。

**为什么没有节点图？**
节点只在内部求值，界面只暴露图层和效果栈。这是刻意设计，不是没做。

**会支持 macOS 吗？**
目前只做 Windows 桌面。
