# Reelix

**特效合成软件。** 主对标 After Effects / Fusion / Nuke，副对标 Premiere Pro。剪辑是它的附属能力，合成才是它的身份——因为做合成必须能摆镜头顺序，所以剪辑轨道内建在同一个软件里，而不是另做一个。

Reelix 是创作软件线里唯一把两件事合在一处的产品。合成与剪辑不分家：图层合成与效果栈、空间识别与相机解算、3D 空间场景、图层与关键帧动画，加上时间线与多轨道剪辑，全在同一个窗口、同一份数据模型里。

> **提醒（用户明确纠正过）：** Reelix **不是剪辑软件**，是**特效合成软件**。所以特效合成里最基础的能力——**识别扫描 3D 空间场景**（相机追踪 / SfM / 三维重建），以及它派生的**摄像机、视频 2D→3D 空间转换**——是地基，不是可选项。详见 [docs/10-特效合成与空间识别.md](docs/10-特效合成与空间识别.md)。

## 一句话说清「合体」是什么

不是把两个面板并排放在一起。并排放是 Premiere 加 After Effects 的工作方式，你要在两边来回跳、来回导。

Reelix 的做法是**内部是一张有向无环图，界面却只有一层**。给一个片段加特效，就是在它的**效果栈**里加一张卡片，自上而下依次叠加，不用连任何线；给整条序列调色，就是把调色挂在序列上。用户在时间线上排片段、在效果栈里摞效果、在曲线编辑器里拧关键帧——看到的全是它们，看不到节点也看不到连线。图只在内部把效果栈编译出来求值。**同一份数据，几个视图**：时间线按时间轴排列，效果栈按处理顺序排列，曲线编辑器管关键帧，选中一个片段，它们立刻同步。

再往上，**关键帧引擎是共享的**：片段的参数能打关键帧，效果的参数也能打关键帧，用的是同一套曲线引擎、同一个曲线编辑器。这是最能体现「一体」的地方。

细节见 [docs/04-剪辑与特效融合设计.md](docs/04-剪辑与特效融合设计.md)。

- 全应用只有**两味色**：**白 + 浅绿**（默认浅色主题，与深色系的 Strata 区分）。强调色 `#26734f`，唯一权威是 `scaffold/src/styles/tokens.css`。小方品牌蓝 `#6fc0ff` 只用于 logo。**严禁紫色，严禁任何第二强调色。**

- **MIT 许可**，非营利，小方工作室出品。
- **不带任何 AI 功能。**
- 全中文界面。Windows 优先。
- 参考项目的代码能不能并入，只认 [docs/06](docs/06-参考项目与许可边界.md) 的许可证白名单，**GPL 一律不进仓库**。
